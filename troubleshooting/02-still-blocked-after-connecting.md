# 02 · 中国向けにつないだのに見られない：どうすればいいか

順番に確認してください。どのステップも 1 分ほどで終わります。

1. **出口の IP が本当に変わっているか確かめる。** ブラウザーで IP の所在地を表示するサイトを開き、中国本土になっているかを見ます。なっていなければ VPN が効いていないので、つなぎ直してください。
2. **IPv6 と DNS の漏れ。** 出口の IP は合っているのに、サイトから海外にいると判定される場合、ほとんどは端末の IPv6 かローカルの DNS が VPN を素通りしています。いちばんよくあるケースなので、専用の記事があります：「[03 · すり抜けているのは IPv6 と DNS](03-ipv6-and-dns-leak.md)」。
3. **アプリのキャッシュ。** 動画や音楽のアプリは、地域判定の結果をキャッシュしています。アプリを完全に終了してから開き直し、それでもだめならアプリのデータを消去してください。
4. **アプリのバージョン。** 国際版（iQIYI の国際版、WeTV）を入れていると、配信されている作品のラインナップが違います。中国本土版に入れ替えてください。
5. **アカウントの登録地域。** 一部のプラットフォームは、現在の IP に関係なく、アカウントを登録した地域でコンテンツを制限しています。この場合は別のアカウントを使うしかありません。
6. **端末の地域と言語。** 端末の地域設定を読み取るアプリもあります。端末の地域を中国に変えてから、もう一度試してください。
7. **接続先の地域。** 省によって IP ごとに見られるコンテンツが違う場合もあります。別の接続先に切り替えて試してください。

## それでも解決しないとき

サポートに次の 4 点を伝えてください。見たいサイトまたはアプリ、エラーの文言そのまま、現在の出口 IP の所在地、使っている接続方法です。これがそろっていれば、一度で原因を突き止められます。
