# 08 · 本当につながっているか、どの地域から出ているかを確かめる

クライアントに「接続済み」と表示されていても、アクセス先のサイトに VPN のアドレスが見えているとは限りません。いちばん簡単な確かめ方は、当サイトの上部バーにあります。「現在のネットワーク」の欄には、**当サイトから見た今のあなた**、つまりどの国、どの省・州、どのネットワークから出てきているかが表示されます。この記事では、この欄の読み方、接続前後の比べ方、6 つの接続方法それぞれでつながっているかの見分け方、地域一覧の赤・黄・緑のランプの意味、「つないだのにまだ地元のまま」のときに自分で確認できることを説明します。

## 上部バーの「現在のネットワーク」に表示されるもの

| 位置 | 内容 |
|---|---|
| 先頭 | 出口のある国の国旗。国を特定できないときは Wi‑Fi のアイコンになります |
| 中央 | 省・州の名前。画面の言語で表示されます（米国、カナダ、オーストラリアなどは CA、ON、NSW のような一般的な略称）。香港、マカオ、シンガポールは地域名がそのまま表示されます |
| 末尾 | ネットワーク名。中国の 3 大キャリアや教育ネットワークなどは、中国語の画面では 电信（中国電信）、移动（中国移動）、联通（中国聯通）、教育网（教育ネットワーク）のような短い名前で表示されます。それ以外は英語のブランド名（Comcast、Bell など）が表示されます |

- **省・州がわからないときは「国旗 · ネットワーク名」だけが表示されます。** 国名で穴埋めはしません。国は国旗でわかります。
- パソコンではこの欄にマウスを重ねると、組織の正式名称、省・州、国コード、**出口 IP** がポップアップで表示されます。この IP はあなたにしか表示されず、サポートに連絡するときにいちばん役立つ情報です。
- Windows の Chrome / Edge には国旗のフォントがないため、国旗は 2 文字（JP、US など）で表示されます。意味は同じです。
- パソコンではログインしてから上部バーに表示されます。スマホではログインしなくても表示されます。

## 接続の前後を比べれば一目でわかる

1. **VPN をオフにした状態で** 当サイトを開いて見てみます。自宅のブロードバンドかモバイルデータ通信のキャリアが表示され、国旗は今いる国のはずです。
2. **VPN をつないでから** ブラウザーに戻ります。国旗が選んだ地域に変わり、ネットワーク名もたいてい自宅のキャリアではなく、データセンターやクラウド事業者の名前に変わります。
3. 前後で同じなら、このブラウザーは当サイトにアクセスするときに VPN を通っていません。下の「つないだのにまだ地元のまま」をご覧ください。

**ページを何度も更新する必要はありません。** この欄は、ブラウザーのウィンドウに戻ったときに自動で確認し直し、ネットワークの変化を検知すると数秒のうちに何度か確認し、ページを開いているあいだも 10〜20 秒ごとに更新されます。つないだ直後にまだ古い値が見えていたら、10〜20 秒待つかウィンドウを切り替えてください。それでも変わらなければ、手動で更新してください。

**中国にいて「中国の接続先」を選んでいる場合**、上部バーに外国が表示されるのは正常です。中国の接続先は振り分けを使っていて、中国のサイトは中国国内から出て、海外のサイトは海外向けの経路で着地します。当サイトは海外にあるので、表示されるのは当然、海外側です。

## 接続方法ごとの、つながっているかの見分け方

| 方法 | クライアントで見るところ | 当サイトの上部バーは変わるか |
|---|---|---|
| Cisco（AnyConnect） | クライアントに「接続済み」と表示される | 変わります。Cisco はつなぐとすべての通信が VPN を通ります |
| Hiddify | クライアントに接続済みと表示される | グローバルモードなら変わります。「自動振り分け」ではリスト次第です |
| OpenVPN | クライアントに接続済みと表示される | 変わります。初期設定ではすべての通信が VPN を通ります |
| プライベートネットワーク（Tailscale） | クライアントがオンラインで、**かつ**「Exit Node」で地域を選んでいる | 出口を選んだときだけ変わります。「None」を選んでいると、端末同士がつながるだけで通信は VPN を通りません |
| プロキシ（Webプロキシ） | 「接続済み」の状態はありません。拡張機能のアイコンでどの地域のモードを選んでいるかを見ます | 拡張機能を入れたブラウザーだけが変わります。「auto switch」（自動切り替え）のルールで当サイトが直接接続になることがあります |
| ルーター | 管理画面でアカウントの状態が正常で、期限日が表示されている | このルーターの Wi‑Fi につないだ端末から見ます。振り分けモードではリスト次第です |

振り分けとは、リストにあるサイトは VPN を通り、それ以外は直接つながる仕組みです。振り分けをオンにしていて上部バーが地元のままでも、つながっていないとは限りません。**一時的に「グローバル」に切り替えてもう一度見てください**。変われば VPN は動いていて、当サイトがリストに載っていないだけです。

## 地域一覧の赤・黄・緑のランプ

Cisco、Hiddify、プロキシ、OpenVPN の各ページでは、地域の国旗の下に小さなランプがあり、プライベートネットワークのクライアントでも出口名の前に同じランプが表示されます。その地域の各サーバーのリアルタイムの平均帯域から自動で判定され、1 分に 1 回ほど更新されます。

| ランプ | 意味 |
|---|---|
| 緑（点灯） | 空いている |
| 黄（点滅） | 使われている |
| 赤（点滅） | 混んでいる |
| ランプなし | その時点でデータが取れなかっただけで、サーバーが止まっているという意味ではありません |

パソコンではランプにマウスを重ねると、その地域の平均負荷が表示されます。

**赤いランプが見えたら：**

- 赤は故障という意味ではなく、その時点で利用者が多いというだけです。すでにつながっていて速度に不満がなければ、そのままでかまいません。
- 遅いと感じたら、緑のランプの地域に切り替えます。Cisco はウェブページで別の国旗をクリックして新しいアドレスをコピー、Hiddify は別の地域の設定を読み込み、プライベートネットワークは「Exit Node」で変更、プロキシは拡張機能のアイコンで別の地域をクリックします。
- 1 つの地域には複数のマシンが控えていて、つなぐときにいちばん空いているものが自動で選ばれます。自分でマシンを選ぶ必要はありません。
- 夜 8 時から 11 時はピークです。この時間帯は緑のランプの地域を選ぶか、接続方法を切り替えてください。それでも遅い場合、原因はたいてい手元のブロードバンドです（集合住宅の共用ブロードバンド、またはキャリアと地域が合っていない）。キャリア別の地域の選び方は「関連記事」をご覧ください。

## つないだのにまだ地元のまま

よくある順に並べています。

1. **振り分けのルールで当サイトが直接接続になっている。** Hiddify の自動振り分け、プロキシの拡張機能の「auto switch」、ルーターの振り分けモードは、どれも当サイトを VPN の外に置くことがあります。一時的にグローバルに切り替えて確かめてください。プロキシを使っている場合は、当サイトをルールに追加する方法もあります。
2. **Webプロキシが対象にするのはそのブラウザーだけ。** 別のブラウザーやスマホのアプリから見れば、当然地元のままです。
3. **プライベートネットワークで出口を選んでいない。** オンライン ≠ VPN を通っている、です。「Exit Node」が「None」のときは、端末同士がつながるだけです。
4. **見ている端末が違う。** ルーターの場合は、そのルーターの Wi‑Fi につないだ端末から見る必要があります。モデムの Wi‑Fi につないだスマホや、モバイルデータ通信のスマホではだめです。
5. **ほかの VPN やメッシュネットワークのツールが同時にオンになっている。** 会社の VPN やほかの事業者の加速器は経路を取り合います。1 つだけにしてください。
6. **まだ更新されていない。** 10〜20 秒待つか、ウィンドウを切り替えるか、手動で一度更新してください。

## 上部バーで見えるのは IP だけ。IPv6 と DNS は別に確認

上部バーが見ているのは、当サイトが受け取った接続の IPv4 アドレスです。正しく表示されていても、それはこのブラウザーが当サイトにアクセスするときに VPN を通ったというだけです。

- **IPv6 と DNS はここではわかりません。** ブラウザーが IPv6 で当サイトにアクセスしたときは、この欄はそもそも表示されません。間違ったネットワークを本物のように見せることはしません。動画サイトに著作権の制限の表示がまだ出るなら、IPv6 か DNS が VPN を素通りしている可能性が高いです。「[03 · すり抜けているのは IPv6 と DNS](03-ipv6-and-dns-leak.md)」をご覧ください。
- **アプリは地域判定の結果をキャッシュしている。** 上部バーは毎回新しく調べるのでキャッシュの影響を受けませんが、動画や音楽のアプリは前の地域を覚えています。完全に終了してから開き直してください。「[02 · 中国向けにつないだのに見られない](02-still-blocked-after-connecting.md)」をご覧ください。

## よくある質問

**上部バーの「現在のネットワーク」の欄が消えました。** パソコンでは、まずログインしてください。ログインしても表示されない場合は、この接続が IPv6 を通ったか、一時的に調べられないかのどちらかの可能性が高いです。10〜20 秒待つか、更新してください。間違ったものを表示するくらいなら、何も表示しないようにしています。

**同じ地域なのに、接続のたびに IP が違います。** 正常です。1 つの地域には複数のマシンが控えていて、接続のたびにその時点でいちばん空いているものが選ばれます。確立済みの接続が途中で別のマシンに移されることはありません。

**表示される省が思っていたのと違います。** 上部バーには出口 IP のある省・州が表示され、精度もそのレベルまでです。国旗が合っていれば、出口は選んだ国や地域にあります。

**サポートに連絡するときは何を伝えればいいですか？** 上部バーのその欄にマウスを重ねてポップアップに表示された内容（出口 IP を含む）を、接続方法、選んだ地域、問題が起きた時刻と一緒に送ってください。
