# 09 · サポートにパソコンやルーターをリモートで見てもらう

グループでスクリーンショットを十数回やり取りしても伝わらない問題が、サポートが画面を直接見れば 2 分で突き止められることがあります。この記事では、リモートサポートを頼む価値があるのはどんなときか、パソコンで使うソフト、当サイトのサーバー設定の読み込み方、接続情報を安全にサポートに渡す方法、セッション中に自分で管理できること、終わったあとのアクセスの取り消し方、当サイトのファームウェアを入れたルーターの場合にすることを説明します。

## リモートサポートを頼む価値があるとき

- 「[01 · つながらない・遅い・切れるときのチェックリスト](01-cannot-connect-slow-drops.md)」を一通り試し、接続方法、地域、エラーの文言そのままかスクリーンショット、問題が起きた時刻を添えて質問したのに、まだ解決しない。
- 手順そのものを説明できない：設定が奥のほうにある、システムの言語が読めない、エラーが一瞬で消えて撮れない。
- 家族のパソコンを手伝っているが、そばにいないし、電話では伝わらない。

次の場合は **リモートサポートを使わず**、グループで文字でやり取りしてください。

- 会社が一元管理しているパソコン。グループポリシーでこの種のプログラムの実行が禁止されていることが多く、社内規定に違反するおそれもあります。

## 使うソフト：RustDesk

ウェブサイトでおすすめしているのは [RustDesk](https://rustdesk.com) です。オープンソース（AGPL-3.0）なのでコードは誰でも検証でき、セッションをいつ始めていつ終えるかは、どちらも自分のクリックで決まります。Windows、macOS、Linux、Android、iOS に対応しています（iPhone / iPad はほかの端末を操作できるだけで、操作される側にはなれません）。

[お問い合わせページ](https://www.leotun.com/ja/contact#downloads)の「ダウンロードセンター」→「リモートサポート」か、公式サイト rustdesk.com からダウンロードしてください。検索結果に出てくる第三者のダウンロードサイトは使わないでください。セッションの両側でインストールが必要です。

## インストール後に許可すること

| システム | すること |
|---|---|
| macOS | 「システム設定 → プライバシーとセキュリティ」の「画面収録」と「アクセシビリティ」の両方で RustDesk にチェックを入れ、完全に終了してから開き直します。片方だけだと「見えるのに操作できない」か、真っ黒な画面になります。「壊れている」と表示される場合は「[06](06-antivirus-false-positive.md)」をご覧ください |
| Android | サポートを受けるときは RustDesk で「サービスを開始」をタップし、画面の録画を許可します。サポートがあなたの画面をタップできるようにするには、システムの「ユーザー補助」でも RustDesk をオンにします |
| Windows / Linux | たいていインストールしてすぐ使えます |

## 当社のサーバーにつなぐ

リモートサポートは当サイトが自前で運営する RustDesk サーバーを通るので、中国国内からでも安定してつながります。**セッションの両側で一度ずつ読み込む必要があります**。両端が同じサーバーを使っていないと、お互いを見つけられません。

1. 先にウェブサイトにログインし、[お問い合わせページ](https://www.leotun.com/ja/contact#downloads)の「ダウンロードセンター」→「リモートサポート」→「当サイトのサーバーに接続」で「コピー」をクリックします。
2. パソコンでは RustDesk の「設定 → ネットワーク」を開き、先に「ネットワーク設定のロック解除」をクリックしてから「ID/リレーサーバー」をクリックします。スマホでは「設定 → ID/リレーサーバー」です。
3. 表示されたウィンドウで右上のクリップボードのアイコンをクリック（スマホでは「インポート」をタップ）します。設定が自動で入力されるので、「OK」をクリックします。

**設定を入力欄に貼り付けないでください**。「failed to lookup address」（アドレスを解決できない）というエラーになります。この設定は当サイトのアカウントで使うためだけのものです。転送しないでください。

## ID とワンタイムパスワードをサポートに渡す

RustDesk を開くと、メイン画面にこの端末の ID とワンタイムパスワードが表示されます。渡す前に、次の 3 点を確認してください。

1. **自分から依頼したこと。** [お問い合わせページ](https://www.leotun.com/ja/contact?utm_source=github&utm_content=troubleshooting-09)に載っている公式グループで問題を説明し、サポートがリモートサポートが必要だと判断してから、次のステップに進みます。当社のサポートスタッフが自分から声をかけてきて、リモートソフトのインストールや接続コードを求めることはありません。誰が求めてきても、まず公式グループで確かめてください。
2. **公式のサポート窓口にだけ送ること**：お問い合わせページに載っている有人サポートの連絡先です。グループの外で「LeoTun のサポート」を名乗る個別チャットは当社ではありません。
3. **グループに投稿しないこと。** グループは大勢が見られる場所です。ID とパスワードの組み合わせは、パソコンの鍵をドアに貼っておくのと同じです。

## セッション中

- セッション中は、画面で何が行われているかを常に見ることができ、RustDesk のウィンドウでいつでも切断できます。
- ウィンドウを最小化してほしい、パソコンから離れてほしい、ネットバンキングや決済アプリを開いてほしい、と言われたら、**すぐに切断してください**。
- アカウントのパスワードを入力する必要があるときは、自分で入力してください。サポートに読み上げてはいけません。

## 終わったあとにアクセスを取り消す

1. RustDesk のウィンドウで切断をクリックし、相手がオフラインになったことを確かめます。
2. ワンタイムパスワードを更新し、さっき渡したものを無効にします。
3. RustDesk を終了します。もう使わないならアンインストールしてかまいません。次に必要になったら、またダウンロードすれば済みます。

## ルーターの場合にすること

当サイトのファームウェアを入れたルーターなら、ルーターにもパソコンにもリモートソフトを入れる必要はなく、ルーターの管理パスワードをサポートに送る必要もありません。すべきことは次のとおりです。

- ルーターの電源を入れ、LAN ケーブルを挿したままにし、ルーターでアカウントにログインした状態にしておく。
- 公式グループでサポートに、アカウント、ルーターの機種、症状を伝える。あとはサポートが対応します。
- 作業中は、サポートに頼まれない限り、電源の抜き差しや再起動を繰り返さない。

## よくある質問

**サポートが自分から個別メッセージを送ってきて、リモートソフトを入れるように言うことはありますか？** ありません。誰かが向こうから声をかけてきたときは、必ず先に公式グループで相手の身元を確かめてください。

**読み込むときに「failed to lookup address」と表示されます。** 設定を入力欄に貼り付けた可能性が高いです。その欄を空にし、「ID/リレーサーバー」のウィンドウに戻って、右上のクリップボードのアイコンをクリックして読み込んでください。

**macOS でつながったのに画面が真っ黒、または見えるのに操作できません。** 許可が足りていません。「画面収録」と「アクセシビリティ」の両方にチェックを入れ、完全に終了してから開き直してください。

**セッションが終わったら、ほかに何をすればいいですか？** 切断、ワンタイムパスワードの更新、プログラムの終了です。この 3 つを済ませれば、相手が再び接続することは二度とできません。
