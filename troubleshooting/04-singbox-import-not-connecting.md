# 04 · Hiddify に読み込んだのにつながらない

> ウェブサイト版（より詳しい内容）：https://www.leotun.com/ja/guides/singbox-subscription?utm_source=github&utm_content=troubleshooting-04

表示されたエラーを下の表で探してください。そもそもの読み込み方は「[サブスクリプションリンクの読み込み方（Hiddify、Clash、Shadowrocket）](../client/02-singbox-subscription-links.md)」をご覧ください。

| 症状 | 原因 | 対処 |
|---|---|---|
| 「サブスクリプションを取得できません」、401 | アカウントの期限が切れたか、パスワードが変更された（パスワードを変えると古い設定はすぐに無効になります。意図した仕様です） | ウェブサイトにログインして有効期間を確認してください。更新またはパスワード変更のあとは、QR コードをもう一度スキャンします |
| 読み込みは成功するが、接続がタイムアウトする | その地域のアドレスが変わったばかりか、その入口が通信事業者に妨害されている | クライアントで「サブスクリプションを更新」（Update subscription）をタップして最新の設定を取り込みます。または別の地域に切り替えます。地域ごとに設定が分かれているので、互いに影響しません |
| つながったのにインターネットが使えない | クライアント独自のルーティングルールで通信が「直接接続」に送られている | デフォルトの送信先をそのノードに変えるか、自分で追加したルールを削除してください |
| スキャンすると「無効な QR コード」と表示される | ポップアップを開いた直後の QR コードは Hiddify / sing-box 用で、ほかのクライアントでそのままスキャンするとこのエラーになります。または他人のスクリーンショットをスキャンした | 先にお使いのクライアントのボタンをクリックすると、QR コードが対応する種類に切り替わるので、それからスキャンするか貼り付けてください。Clash 系のクライアントは「Clash サブスクリプション」、Shadowrocket / NekoBox / v2rayN などは「共有リンク」をクリックします。QR コードにはあなた自身の認証情報が入っているので、他人のものは使えません |
| 速度が遅い | 選んだ地域の負荷が高い、または自宅の回線と地域の相性が悪い | ウェブサイトの地域一覧の赤・黄・緑のランプを見て、緑の地域に切り替えてください。それでも遅ければ、通信事業者に合わせて地域を変えます |
| Clash 系のクライアントで共有リンクを読み込めない | Clash Meta、Clash Verge、FlClash、Stash などは、hysteria2:// の 1 行をプロファイルとして読み込めません | 「Clash サブスクリプション」のボタンをクリックし、URL をクライアントのサブスクリプション一覧に貼り付けてください。元祖の Clash や Clash for Windows はコアに hysteria2 がないので、mihomo コアのクライアントを使ってください |
| 共有リンクを読み込めない、またはつながらない | 共有リンクが一部のクライアントでは解析できない拡張形式を使っている | Hiddify に切り替えてください |

## 更新、プラン変更、パスワード変更のあとに読み込み直す必要はあるか

- **更新やプラン変更（個人 / ファミリー / ビジネス）**：不要です。今の設定がそのまま使えます。
- **パスワード変更**：古い設定はすぐに使えなくなるので、QR コードをもう一度スキャンしてください。スマホをなくしたりリンクが漏れたりしたときは、この方法でアクセスを無効にできます。
- **アカウントの期限切れ**：設定は 401 を返します。更新後に新しい設定は不要で、接続し直すだけです。
- **2026 年 9 月より前に読み込んだもの**：IPv6 を拒否するルールが入っていないので、海外から中国の動画を見ると著作権の制限の表示が出ます。削除して読み込み直してください。「[03](03-ipv6-and-dns-leak.md)」を参照してください。

クライアント名とバージョン、地域、エラーの正確な文言かスクリーンショット。この 3 つをサポートに伝えてください。
