# 06 · Mac でアプリが「壊れている」と表示されたら

> ウェブサイト版（より詳しい内容）：https://www.leotun.com/ja/guides/antivirus-false-positive?utm_source=github&utm_content=troubleshooting-06

先に結論です。ファイルは壊れておらず、誰かに改ざんされてもいません。Mac で Hiddify をダブルクリックしたときに「壊れているため開けません」や「開発元を検証できません」と表示されるのは、システムの Gatekeeper がブロックしているためです。以下の手順で許可してください。

Windows では、現在のテストで Hiddify をインストールしてもウイルス警告は出なくなっています。それでもご自身で入れたウイルス対策ソフトが検知する場合は、ここと同じ順番、つまり「まず確認、それから許可」で対処してください。

## ブロックされる理由

**ウェブページからダウンロードしたファイルには、隔離のフラグが付きます。** macOS の Gatekeeper はこのフラグを見るとアプリをブロックします。メッセージは「壊れている」のときもあれば「開発元を検証できません」のときもありますが、原因は同じです。

当社のしていること：デスクトップ版クライアントは、上流のオープンソースプロジェクトが公開しているリリースパッケージの **無改変のミラー** です。手を加えたり、パッケージし直したり、何かを埋め込んだりはしておらず、ダウンロードしやすいように自社のダウンロードサイトに置いているだけです。

## やみくもに許可せず、まず自分で確かめる

アプリを許可すると、システムはそのアプリをチェックしなくなります。ですから順番は「まず確認、それから許可」です。

**VirusTotal にアップロードして再確認する。** インストーラーを [virustotal.com](https://virustotal.com/gui/home/upload) にドラッグします。ヒューリスティック型のエンジンがいくつか検知していても、主要ベンダーがすべて問題なしとしているなら、典型的な誤検知のパターンです。主要なエンジンの多くが検知している場合は **インストールしないで**、すぐ当社にご連絡ください。

確認で問題がなかった場合だけ先に進んでください。判断がつかないときは、先にサポートにご連絡いただければ、ダウンロードサイトを確認します。

## 許可する 3 つの方法（範囲の狭い順）

ダブルクリックすると、「“クライアント名”は壊れているため開けません。ゴミ箱に入れる必要があります。」や「開発元を検証できないため開けません」と表示されることがあります。以下の 3 つの手順は範囲の狭い順に並んでいます。**1 つ目で開けたら、3 つ目は使わないでください**。

1. Finder の「アプリケーション」でアプリを見つけ、Control キーを押しながらアイコンをクリック（または右クリック）して「開く」を選び、表示されたダイアログでもう一度「開く」をクリックします。このアプリだけを 1 回限り許可する方法です。
2. 右クリックメニューに使える「開く」がない場合は、「システム設定」→「プライバシーとセキュリティ」を開き、下の「セキュリティ」の欄までスクロールします。「“クライアント名”は開発元を確認できないため、使用がブロックされました」と表示されているので、右側の「このまま開く」をクリックし、パスワードを入力して確定します。
3. メッセージが「壊れている」の場合、最初の 2 つの手順はたいてい効きません。「ターミナル」を開き、`sudo xattr -dr com.apple.quarantine` に続けてアプリのパス（通常は `/Applications/` の下の `.app`）を入力して Return キーを押し、ログインパスワードを入力してから、もう一度アプリを開きます。このコマンドは、ダウンロード元を示す隔離のフラグを取り除くものです。

初回の起動時には、ネットワーク拡張機能のインストールを許可するためにパスワードも求められます。同意して初めて、アプリが通信を引き受けられるようになります。

いくつかの注意点：

- `xattr` のコマンドは、**入手元を確認済みのファイルにだけ** 使ってください。確認の方法は前の節にあります。
- `sudo spctl --master-disable` で Gatekeeper をまるごと無効にするのは **やめてください**。Mac 全体の保護が切れてしまいます。右クリックで「開く」なら、影響はそのアプリだけです。
- macOS 15 以降、Apple は右クリックで「開く」の手順を厳しくしており、たいていは「システム設定」の手順を通る必要があります。これはシステムの動作の変更で、当社のパッケージの問題ではありません。
- 会社から支給された Mac は MDM のプロファイルで管理されていることが多く、上の 3 つの手順がどれも使えない場合があります。無理をせず、下の 3 つの選択肢を使ってください。

## 許可したくないなら、この 3 つのどれかを

これらのクライアントは **macOS でダブルクリックするだけで使え**、上のようなメッセージは出ません。アカウントは同じもので、追加料金もかかりません。

- **プライベートネットワーク（Tailscale 公式クライアント）**：インストールすればすぐ使え、つけっぱなしにしておくのに向いています
- **OpenVPN Connect**：OpenVPN 自身のインストーラーで、設定を読み込むだけです
- **Cisco Secure Client**：企業向けのクライアントで、多くの会社のパソコンにすでに入っています

## よくある質問

**そちらのプログラムに本当にウイルスは入っていないのですか？**
入っていません。上流のオープンソースプロジェクトの公式リリースパッケージを無改変でミラーしたものです。とはいえ、当社の言葉をうのみにする必要はありません。自分で確かめる方法は上に書いたとおり、VirusTotal にアップロードして各エンジンの判定の分布を見ることです。

**Windows でもまだ検知されますか？**
現時点のテストでは、Windows 標準のセキュリティ センターは Hiddify のインストールを検知しなくなっています。それでもご自身で入れたウイルス対策ソフトが検知する場合は、先に VirusTotal で再確認し、問題がなければウイルス対策ソフトで Hiddify のインストール先フォルダーを信頼済みに設定してください。インストールのためにリアルタイム保護をオフにするのはやめてください。

**Mac でインストールしたのに開きません。ダウンロードが壊れたのですか？**
いいえ。開かないのは Gatekeeper がブロックしているからです。上の「許可する 3 つの方法」で対処してください。

**Mac にもウイルス対策ソフトを入れたほうがいいですか？**
いいえ。macOS でブロックしているのはシステム標準の Gatekeeper で、ウイルス対策ソフトではありません。他社のウイルス対策ソフトを入れてもこのメッセージは消えず、新たなブロックが増えることもあります。

**スマホでもこの問題は起きますか？**
iOS では App Store からインストールするので、この問題はありません。Android ではまれに提供元不明のアプリとして警告されますが、許可すれば大丈夫です。
