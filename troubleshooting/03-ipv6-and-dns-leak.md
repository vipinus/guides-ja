# 03 · つながっているのに動画サイトに著作権の表示が出る：すり抜けているのは IPv6 と DNS

> ウェブサイト版（より詳しい内容）：https://www.leotun.com/ja/guides/overseas-video?utm_source=github&utm_content=troubleshooting-03

「[02 · 中国向けにつないだのに見られない](02-still-blocked-after-connecting.md)」のステップ 1 はクリアしている、つまり出口の IP は中国本土と判定されているのに、サイトにはまだ「著作権の制限により再生できません」と表示される。こういう場合、たいていは端末にまだ VPN を通らない経路が残っています。**IPv6** か **DNS** です。動画サイトは見えたアドレスから利用者の場所を判断するので、1 本でも漏れていれば、相手には海外からのアクセスに見えます。

## なぜ漏れるのか

- 最近の端末は IPv4 と IPv6 の両方のアドレスを持っていて、ブラウザーは IPv6 を優先します。VPN が IPv4 しか引き受けていないと、IPv6 のリクエストは自宅の回線からそのまま出ていきます。
- ブラウザー内蔵の「セキュア DNS」、Android の「プライベート DNS」、動いているほかのメッシュネットワークツール（Tailscale など）は、どれも VPN より先に名前解決を引き受けてしまいます。

「接続済み」はトンネルができたというだけで、すべての通信がトンネルを通っているという意味ではありません。

## 5 つのステップで確認

1. **IPv6 を確認します。** 接続後に「test ipv6」で検索してテストページを開きます。IPv6 の欄に今いる国のアドレスが表示されたら → 原因はここなので、ステップ 2 へ。両方の欄が中国本土、または IPv6 が使えないと表示されたら → ステップ 3 へ。
2. **IPv6 をオフにするか、IPv6 を遮断するクライアントに切り替えます。** Windows：ネットワークアダプターのプロパティで「インターネット プロトコル バージョン 6 (TCP/IPv6)」のチェックを外します。macOS：ネットワーク設定 →「TCP/IP」で IPv6 の構成を「リンクローカルのみ」にします。スマホ：Wi‑Fi をオフにしてモバイルデータ通信で一度試します。自宅の回線にはたいてい IPv6 がありますが、携帯会社のモバイル通信にはないことが多いです。
3. **DNS を確認します。** Chrome の「設定」→「プライバシーとセキュリティ」で「セキュア DNS を使用する」をオフにします。Android では「プライベート DNS」をオフにします。ほかの VPN、メッシュネットワークツール、プロキシ拡張機能は終了してください。
4. **アプリを完全に終了してから開き直します。ウェブ版ならサイトのデータを消去します。** 配信サービスは前回の地域判定をキャッシュしています。
5. **別の入口に切り替えて試します。** ある出口のアドレスが、ちょうど配信サービスにマークされたばかりかもしれません。

## LeoTun の対応

2026 年 9 月から、LeoTun の 3 つの接続方法（Hiddify、Cisco AnyConnect、OpenVPN）はすべて、トンネル内で IPv6 を直接拒否し、名前解決をトンネル内で行わせる DNS 設定を配布しています。端末側で設定を変える必要はありません。**9 月より前に読み込んだ Hiddify の設定にはこのルールがありません。削除して、QR コードをスキャンして読み込み直してください。**

ルーターの場合はそもそも漏れません。LAN 全体がルーターを通って出ていくので、端末の IPv6 や DNS が外に出ることはありません。

## それでも表示が出るケース

| ケース | 症状 | 対処 |
|---|---|---|
| 出口が中国本土ではない | IP を調べると香港 / 台湾 / 日本と表示される | 中国の入口に切り替えてください。テンセントビデオや iQIYI にとっては、香港や台湾のアドレスも海外扱いです |
| 独自のルーティングルールで動画のドメインを「直接接続」にしている | ウェブページは開くのに、動画が再生されない | 中国のドメインをノード経由に変えてください。海外にいる方は「中国は直接接続」をオンにしないでください |
| Webプロキシを使っている | ブラウザーでは見られるが、アプリでは見られない | 動画を見るには端末全体のトンネルが必要です。Webプロキシがカバーするのはブラウザーだけです |
