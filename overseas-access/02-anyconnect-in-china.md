# 02 · Cisco AnyConnect は中国で使えるか

> ウェブサイト版（より詳しい内容）：https://www.leotun.com/ja/guides/anyconnect-china?utm_source=github&utm_content=overseas-access-02

使えます。AnyConnect は Cisco の企業向け VPN プロトコルで、世界中の企業がリモートワークに使っており、外資系企業の中国拠点でも毎日使われています。そのため、まるごと禁止するには代償が大きすぎます。**実際にブロックされるのは特定のサーバーのアドレスで、プロトコルではありません。** つまり「使えるかどうか」は、提供元が十分な数のアドレスを持ち、素早く差し替えられるかで決まります。

## 独自の VPN アプリよりブロックに強い理由

| | AnyConnect | 独自の VPN アプリ |
|---|---|---|
| 通信の特徴 | 標準的な TLS で、HTTPS のサイトを見るのと同じ | 独自プロトコルで、特徴が固定されている |
| 識別されたら | その 1 つのアドレスがつながらなくなるだけ | アプリ全体が使えなくなる |
| クライアント | Cisco が配布。オープンソースの代替 OpenConnect も全プラットフォームにある | アプリストアから消えたらおしまい |

LeoTun は 24 の地域で自前のマシンを運用しています。アドレスに目をつけられたら新しいものに差し替え、ドメイン名の向き先も自動で切り替わるので、クライアントに保存したアドレスを変える必要はありません。

## インストール方法

1. ウェブサイトの Cisco ページから、お使いのシステム用のインストーラーをダウンロードします。Windows 10 以降、macOS、iOS、Android、Linux に対応しています。Windows 7/8 は、対応する最後のバージョンである 4.9 しか使えません。
2. クライアントを開き、アドレス欄にサーバーのアドレスを入力します。ウェブサイトで地域の国旗をクリックするとコピーできます。
3. アカウントとパスワードを入力して接続します。証明書ファイルも設定の読み込みも不要です。
4. 「Connected」（接続済み）と表示されたら、出口の IP を確認します。

## つながらないときは、この順番で

1. **別の地域に切り替える。** ほかの地域でつながるなら、そのサーバーに一時的に届かないだけです。
2. **ネットワークを切り替える。** ブロードバンドでだめならモバイルデータに、その逆も試します。キャリアごとに干渉のタイミングは違います。
3. **エラーを読む。** `Login failed` はアカウントやパスワード、または期限切れです。`Untrusted server certificate` は、システムの時計がずれているか、いまのネットワークが TLS を傍受している可能性が高いので、ネットワークを切り替えてください。アドレスに届かないことを意味するのは `Connection attempt has failed` だけです。
4. **クライアントをアップデートする。** OS の大型アップデートのあとは特に重要です。
5. **接続方法を切り替える。** 同じアカウントで OpenVPN や Hiddify を使って同じサーバーにつなげます。3 つのプロトコルのブロックは互いに無関係です。「[02 · どの接続方法がどんな場面に合うか](../network/02-choose-your-connection-method.md)」をご覧ください。

## Cisco AnyConnect のアップデート

Cisco は名前を Cisco Secure Client に変えましたが、使い方は同じです。先にアンインストールする必要はなく、古いバージョンの上に新しいバージョンを入れれば、保存したアドレスはそのまま残ります。スマホは App Store / Google Play でアップデートします。ストアで検索しても見つからないときは、同じプロトコル・同じアカウントで使えるオープンソースの OpenConnect を使ってください（iOS のストアの国・地域の変え方は「[クライアント 06](../client/06-ios-app-store.md)」を参照）。

## よくある質問

**遅いのは速度制限されているからですか？** まず地域を切り替えてください。ウェブサイトの地域一覧にある赤・黄・緑のランプを見て、緑のものを選びます。それでも遅いなら、たいていは手元のブロードバンドが原因です。集合住宅の共用ブロードバンドか、キャリアと地域が合っていないかです（北部の中国聯通なら日本か韓国、南部の中国電信なら東南アジアかオーストラリア、そのほかの事業者なら中国の接続拠点を経由する地域）。

**同じアドレスなのに、良いときと悪いときがあるのはなぜですか？** アドレスはドメイン名で、その裏のマシンはブロックや負荷に応じて自動で入れ替わります。1〜2 分待ってから試せば、たいていは切り替えの途中にぶつかっていただけです。

**長時間つないでいると勝手に切れますか？** 時間で切れることはありません。アカウントの期限が切れるとサーバーが切断するので、更新してからつなぎ直してください。
