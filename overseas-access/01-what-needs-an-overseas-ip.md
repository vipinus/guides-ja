# 01 · 海外の IP が必要なサービスと、経路の仕組み

判断の基準は、海外から中国にアクセスする場合のちょうど裏返しです。サービスから見てあなたの接続元の IP が中国本土にある、あるいはそもそもサーバーに届かない場合、そのサービスは開かない、機能が制限される、極端に遅い、のどれかになります。下の表は用途別にまとめたものです。

| 分類 | 例 | 経路がないとどうなるか | IP のほかに必要なもの |
|---|---|---|---|
| 仕事 | Google Workspace、Slack、Zoom、Teams、Notion | 開かない、または頻繁に切れる | 会社のアカウント |
| 開発 | GitHub、npm、Docker Hub、ミラー以外の PyPI ソース、Stack Overflow | タイムアウトするほど遅い | なし |
| AI | ChatGPT、Claude、Gemini | 開かない | アカウントの登録国、電話番号 |
| 研究 | Google Scholar、論文データベース、大学のメール | 開かない、または極端に遅い | 大学のアカウント |
| ゲーム | Steam の海外リージョン、PSN、ニンテンドー eショップ、海外サーバー | ストアが開かない、遅延が大きい | そのリージョンのサーバー用アカウント |
| 動画と音楽 | YouTube、Netflix、Disney+、Spotify | 開かない | 有料アカウント。アカウントの地域と IP が一致している必要があります |
| SNS | X、Instagram、Telegram、Discord、WhatsApp | 開かない | 電話番号 |

## 大事な区別

**「海外の IP が必要」と「海外のアカウントが必要」は別のことです。** GitHub や YouTube は IP を変えるだけで十分ですが、Netflix は地域の一致する有料アカウントが必要で、ChatGPT の登録には認証コードを受け取れる海外の電話番号が必要です。経路が解決するのは「開けるかどうか」で、アカウントはご自身で用意する必要があります。

## 経路の仕組み

あなたの通信はまず暗号化されて海外のサーバーに送られ、そのサーバーが代わりに目的地にアクセスします。目的地から見えるのは、そのサーバーの IP です。方法はクライアント、Webプロキシ、ルーターの 3 つです。選び方は「[どの接続方法がどんな場面に合うか](../network/02-choose-your-connection-method.md)」をご覧ください。

## よくある 3 つの誤解

- **DNS を変えても解決しません。** つながらないのは経路の問題で、名前解決の問題ではありません。
- **速度は 2 地点を結ぶ経路で決まります。** 中国から外に出る場合、ボトルネックは国境をまたぐ回線と通信事業者の出口なので、サーバーの性能より地域選びのほうが重要です。「[03](03-which-region-is-fastest.md)」をご覧ください。
- **中国のアプリを使っているあいだ、すべてを経路に通す必要はありません。** スプリットルーティング（振り分け）をオンにすれば、デフォルトではブロックされているサイトだけが経路を通り、中国のサイトや、中国からでも普通に開ける海外サイトは直接つながるので、どちらも遠回りしません。「[ルーターのスプリットルーティング](../router/03-router-split-routing.md)」をご覧ください。
