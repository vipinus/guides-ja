# 中国から海外へ · 中国国内から海外のサービスを使う

中国にいて、仕事、開発、研究、ゲーム、動画に必要な海外のサービスが開かない、またはひどく遅い。そんな場面ごとに 1 記事ずつ、**何が必要か、どう選ぶか、どんな落とし穴があるか**をはっきり説明します。

**家族全員やオフィス全体で使うなら**：「[ルーターのスプリットルーティング](../router/03-router-split-routing.md)」をご覧ください。デフォルトでは、ブロックされたサイトだけが経路を通り、中国のサイトや中国からでも普通に開ける海外サイトは直接つながります。端末には何もインストールする必要がありません。
