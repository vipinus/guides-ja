# 07 · AI ツール（ChatGPT、Claude、Gemini など）を使う

## 起きること

中国国内からこれらのサイトを開くと、症状がまちまちなので判断を誤りやすくなります。

| 症状 | いちばん考えられる原因 |
|---|---|
| ページがまったく開かない | ネットワークのレベルで届いていない |
| ページは開くが、ログインで止まる | ログインに使う外部サービスに届いていない |
| チャットはできるが、長い文を送るとすぐ切れる | 接続が不安定 |
| 「お住まいの国では利用できません」と表示される | 提供元が IP で拒否している |
| アカウントが停止された、または認証が必要だと表示される | 下の「いちばん大事なこと」をご覧ください |

## いちばん大事なこと：速さより安定

これらのサービスは、**IP が頻繁に変わること**に特に敏感です。接続がさっきは日本から、いまはアメリカから出ていると、提供元からは「同じアカウントが数分のうちに何か国もまたいでいる」ように見え、リスク管理に引っかかりやすくなります。軽ければ再認証を求められ、重ければアカウントが停止されます。

なので、AI ツールを使うときは：

- **地域を 1 つ決めて使い続け**、頻繁に切り替えない
- 登録と普段の利用は、できるだけ**同じ地域**で
- アメリカ経由で登録したなら、以後もアメリカを使い続ける

これは「どの地域が速いか」よりずっと大事です。少し遅くても待ち時間が少し延びるだけですが、アカウントに問題が起きたら一からやり直しです。

## どの地域を選ぶか

日本とシンガポールは近くて遅延が少なく、普段のチャットではいちばん快適です。ただし注意点が 2 つあります。

- サービスによっては地域ごとに使える範囲が違うので、登録前にその地域から普通に開けるか確認してください
- 使いたい機能に支払いが絡むなら、支払い方法の国と選ぶ地域が食い違わないほうが無難です

迷ったら、無料トライアルで使う予定の各サービスを開いて様子を見てから、長く使う地域を決めてください。

## クライアントのアプリ別振り分けがとても便利

AI ツールはふつうブラウザーか専用アプリで使います。それだけを経路に通すリストに入れ、ほかのアプリは手元のネットワークのままにしておきます。利点は次のとおりです。

- 中国のフードデリバリー、配車、決済のアプリに影響しない
- ほかのアプリのせいで地域が「勝手に切り替わる」ことがない
- データ通信量の節約になる

## コマンドラインと API

コマンドラインツールやコードから API を呼び出す場合、そうしたプログラムは**システムのプロキシを読むとは限りません**。その場合は「[05 · Linux とコマンドライン](05-linux-server.md)」をご覧ください。

## 注意

会社の機密、顧客のデータ、未公開のコードをこれらのサービスに貼り付けないでください。どの経路を使うかとは関係なく、送った内容は相手のサーバーに残ります。
