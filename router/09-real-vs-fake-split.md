# 09 · ルーターの振り分けはどう動くのか

> ウェブサイト版（より詳しい内容）：https://www.leotun.com/ja/guides/router-smart-split?utm_source=github&utm_content=router-09

どれも「スマート振り分け」と呼ばれているのに、なぜか使いにくいルーターがあります。振り分けそのものについては「[03](03-router-split-routing.md)」をご覧ください。この記事では、振り分けが本来やるべきこと、その一部が欠けているときに出る症状、当社のルーターでのやり方だけを説明します。

## ひとことで言うと

振り分けが本来やるべきことは、各ウェブサイトを**その画像、動画、ログインまで含めて**、場所に応じて VPN 経由か直接接続かに振り分け、しかも**家じゅうの端末を同じルールに従わせる**ことです。その一部しかできていないと、次のような症状が出ます。

## 症状の比較

| 見えること | 裏で起きていること |
|---|---|
| 振り分けをオンにしたら、かえって中国のサイトが遅くなった | 中国のサイトが海外のサイトと誤判定され、全体が海外を回って戻ってきている |
| ページは開くのに、動画が読み込み中のまま、画像が出ない、ログインが止まる | リストにメインのサイトしか載っておらず、同じサイトの動画、画像、ログインが別の道を通っている |
| 海外にいて中国向けの経路をつないでいるのに、動画アプリに「仅限中国大陆」（中国本土限定）と出る | 通信の一部が VPN に入らず、サイト側に海外のアドレスが見えている |
| スマホでは再生できるのにテレビやテレビボックスではできない、あるパソコンだけどうしても VPN を通らない | その端末が独自のネットワーク設定を持っていて、ルーターを迂回している |
| 銀行や決済アプリで「別の場所からのログイン」という警告がときどき出る | 同じアプリの通信が、あるときは中国から、あるときは海外から出ている |
| 使っているうちに振り分けが消える（再起動や再接続のあと、全部 VPN 経由か全部直接になる） | 設定が保存されていない |

どれも**エラーは出ません**。ルーターはずっと「接続済み」と表示しているので、いちばん原因を探しにくく、結局「経路が悪い」と思ってしまう人が多いのです。

## 振り分けが本来やるべきこと

- 1 つのサイトは、ページ、画像、動画、ログインまでまとめて同じ道を通り、ばらばらにならない
- 「中国か海外か」を判定するとき正しい側に立ち、中国のサイトが遠回りしない
- 家じゅうの端末が同じルールに従い、端末側でネットワーク設定を変えても回避できない
- 選んだ地域に応じて向きが自動で変わる（海外から中国へと、中国から海外へは、正反対の 2 組のルール）
- リストは自分で更新され、書き込み直す必要がない
- 設定は保存される：再起動や再接続のあとも変わらない。一度オフにしたら、勝手にオンに戻らない

## 当社のルーターのスマート振り分け

| | やり方 |
|---|---|
| スイッチ | デフォルトでオン。中国の地域を選ぶと海外から中国への向き、海外の地域を選ぶと中国から海外への向きが自動で適用されます。中国から海外への向きには「Blocked sites only」（ブロックされたサイトのみ）のチェックボックス（「VPN 設定」→ スマート振り分け）もあり、デフォルトでチェックが入っています。チェックを外すと、中国のサイトは直接、それ以外はすべて VPN 経由になります。2026 年 10 月より前に書き込んだファームウェアにはまだこのチェックボックスが表示されないので、カスタマーサービスに連絡して遠隔で変更してもらってください |
| リスト | 「サイト単位」でまとめています。ページと、そのページが使う動画、画像、ログインの配信元が一緒です |
| 中国から海外へ | デフォルトでは、ブロックされているサイトやサービスだけが VPN を通ります（毎日自動で更新されるブロック対象サイトのリストと、Telegram のように固定のアドレスにつなぐサービスが基準）。中国のサイトや、中国からでも普通に開ける海外サイト（海外企業のサイト、Apple や Microsoft のダウンロード、ゲームのプラットフォーム）は遠回りせず直接つながり、ルーターがないときと同じ速さです |
| 家の端末 | まとめて引き受けます。端末側でネットワーク設定を変えてもルールに従い、ルーターを回避する「裏口」はありません |
| 更新 | リストとルールはルーターの起動時に自動で更新され、ブロック対象サイトのリストは毎日も自動で更新されます |
| 保存 | 再接続や再起動のあとも保たれます。一度オフにしたらオフのままです |
| ローカルネットワーク | プリンター、NAS、カメラはこれまでどおり直接つながります |

**あなたの協力が必要な唯一のケース**：スマホやブラウザーで「プライベート DNS」や「セキュア DNS」のような暗号化の設定がオンになっていると、端末が自分で暗号化して名前を調べるため、ルーターからは見えません。調子のおかしい端末がある場合や、ほかは問題ないのにブロックされたサイトだけ開かない場合は、まずこの種の設定をオフにしてください。

## 自分で確かめる

1. 中国にいる場合（海外のサービスへアクセス）：Baidu や Taobao、Apple や Microsoft のダウンロードのように中国からでも普通に開ける海外サイトが、いつもどおりの速さで開く。ブロックされている海外サイトが開き、動画も再生できる。
2. 海外にいる場合（中国へアクセス）：テンセントビデオや iQIYI で適当なエピソードを選んで再生でき、「仅限中国大陆」（中国本土限定）の表示が出ない。現地の銀行やショッピングサイトもいつもどおり使える。
3. すべての端末、特にテレビとテレビボックスで試す。おかしい端末があれば、まず「プライベート DNS / セキュア DNS」を確認し、次にモデムではなくこのルーターの Wi‑Fi につながっているか確認する。
4. 振り分けでは開かないサイトがある：一時的に「グローバル」に切り替える。グローバルでは開いて振り分けでは開かないなら、まだリストに載っていません。アドレスをカスタマーサービスに送ってリストに追加してもらえば、自動更新で届きます。中国にいる場合は、スマート振り分けの欄で「Blocked sites only」のチェックを外して試す方法もあります。それで開けば、やはりブロックされているのにまだリストに載っていないサイトです。

## よくある質問

**スマート振り分けは自分でオンにする必要がありますか？** いいえ。アカウントにログインして地域を選べばオンになります。

**海外から中国へと、中国から海外へは、別々に設定する必要がありますか？** いいえ。向きは選んだ地域で自動的に決まります。

**プリンターや NAS に影響はありますか？** ありません。家のネットワークの機器はこれまでどおり直接つながります。
