# ルーターとホームネットワークのガイド

家じゅうの端末をまとめて VPN につなぐ方法です。プリインストール済みルーターの使い始め、ファームウェアの書き込み、振り分けの仕組み、テレビと高齢の家族、紐付けとルーターの交換を扱います。

**いちばん質問の多い記事：[ルーターで海外から中国の動画サイトを見られるようにする](06-unlock-chinese-video-with-router.md)**。テレビ、セットトップボックス、家じゅうの端末を一度で設定でき、Wi-Fi につなぐだけで iQIYI、テンセントビデオ、央視頻（CCTV のアプリ）を見られます。
