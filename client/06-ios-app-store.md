# 06 · iOS でアプリをインストールできないとき

iPhone で Hiddify、Tailscale、Telegram が見つからない、あるいは「このAppは現在、お住まいの国または地域では入手できません」と表示される場合、アプリが消えたわけではありません。App Store は Apple ID の地域ごとにストアが分かれていて、中国のストアにはネットワーク系のアプリがほとんど並んでいないのです。iOS では、中国以外の地域の Apple ID で App Store からインストールします。手順はこのページにあります。今のアカウントの地域を変えるより、新しく作るのがおすすめです。以下では、手順、支払い方法に「なし」を選ぶコツ、他人と共有されたアカウントを絶対に使ってはいけない理由を説明します。

## なぜこうなるのか

App Store は Apple ID の地域ごとにストアが分かれていて、地域によって並ぶアプリが違います。中国のストアには Hiddify も Tailscale もなく、Telegram や Discord も出たり消えたりします。Cisco Secure Client と OpenVPN Connect はほとんどの地域で入手できます。これは取り扱いの違いでアプリの問題ではないので、ほかの地域のアカウントならインストールできます。

iPhone では、当サイトの Hiddify もプライベートネットワーク（Tailscale）も App Store からインストールします。下の手順でほかの地域の Apple ID に切り替えるだけです。Android、Windows、macOS 用のインストーラーは当サイトから直接提供しているので、影響を受けません。

## 方法 1（おすすめ）：中国以外の地域の Apple ID を新しく作る

1. 今の App Store のアカウントからサインアウトします。「設定」→ いちばん上の自分の名前 →「メディアと購入」→「サインアウト」。サインアウトするのは App Store だけで iCloud ではないので、写真、バックアップ、連絡先には影響しません。
2. App Store で無料アプリを探して「入手」をタップし、案内に従って「Apple ID を新規作成」を選びます。地域はアメリカ、香港、日本、シンガポールのどれでもかまいません。支払い方法は「なし」を選びます。この「なし」は、無料アプリのダウンロード中に登録する流れでしか表示されず、ウェブで直接登録すると選べないことがよくあります。
3. 新しいアカウントで App Store にサインインし、Hiddify、Tailscale、Telegram を検索してダウンロードします。
4. インストールが済んだら元のアカウントに戻してかまいません。インストール済みのアプリは普通に使え、アップデートも届きます。新しいアプリを入れたくなったら、また切り替えてください。

## 方法 2：今のアカウントの地域を変える

account.apple.com にサインインして国または地域を変更します。先にすべてのサブスクリプションを解約して残高を使い切る必要があり、場合によってはその地域の支払い方法の登録も求められ、元に戻すのも同じくらい手間がかかります。もともと長期的に地域を変えるつもりでなければ、おすすめしません。

## 絶対にやってはいけないこと

- 他人と共有された Apple ID は使わないでください。グループやネット上の「共有アカウント」も同じです。アカウントの持ち主はあなたの端末を遠隔でロックでき、ロックされた iPhone は持ち主にしか解除できません。2 ファクタ認証は一度オンにするとオフにできず、リスクやトラブルはすべてあなたにかかります。当サイトのサポートも共有アカウントは一切提供しません。
- 出どころのわからない構成プロファイルや「エンタープライズ証明書で署名された」インストーラーを入れないでください。ストアを迂回するよくある手口で、証明書を仕込んで通信を乗っ取る入り口にもなります。

## インストールしたあと

Hiddify：当サイトの Hiddify ページに戻ってコードをスキャンするか、「sing-box サブスクリプション」のボタンをタップしてコピーし、Hiddify に切り替えて追加します。Tailscale：先に公式アカウントからログアウトし、プライベートネットワークのページの手順に従って当サイトのコントロールサーバーのアドレスを入力します。Telegram、Discord：当サイトのお問い合わせページでコードをスキャンしてグループに参加します。

## よくある質問

**ほかの地域で登録するのにクレジットカードは必要ですか？** 不要です。方法 1 の流れ（無料アプリのダウンロード中に登録する）なら、支払い方法に「なし」を選べます。

**新しいアカウントは iCloud や写真に影響しますか？** しません。アカウントを切り替えるのは App Store だけで、iCloud は元のアカウントのままです。

**iPad でも同じですか？** 同じです。iPadOS も App Store のルールは同じです。

**Android のスマホでも同じ問題がありますか？** ありません。Android、Windows、macOS、Linux 用のインストーラーは当サイトから直接配布しており、アプリストアに依存しません。
