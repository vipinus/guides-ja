# 07 · Telegram と Discord のインストール

どちらも海外で暮らす中国系の人たちに広く使われているグループチャットのツールで、サポートグループもここにあります。インストール自体は難しくなく、つまずくのはたいてい「アプリストアが開かない」ことです。

## Telegram

| プラットフォーム | インストール方法 |
|---|---|
| Windows / macOS / Linux / Android | [当サイトのお問い合わせページ](https://www.leotun.com/ja/contact?utm_source=github&utm_content=client-07)で公式版と同じインストーラーを配布しています（Android は公式の完全版 APK で、Google Play は不要）。公式サイト <https://desktop.telegram.org> や Google Play からも入手できます |
| iOS | App Store のみ。ストアの国・地域の問題は[前の記事](06-ios-app-store.md)をご覧ください |

登録には SMS を受け取れる携帯電話番号が必要です。登録後はユーザー名を設定でき、ほかの人に番号を知られずに済みます。

## Discord

| プラットフォーム | インストール方法 |
|---|---|
| Windows / macOS / Linux | 公式サイト <https://discord.com/download> |
| Android | 公式の配信は Google Play のみ。Play を入れられないスマホでは分割パッケージ（.apks）を使えます。先にオープンソースのインストーラー SAI を入れる必要があり、arm64 の端末にしか対応していません |
| iOS | App Store |

## インストールしたら

- グループに入る前にルールを読んでください。ほとんどのグループは宣伝を禁止しています。質問の前にグループの履歴を検索してください。多くの質問にはすでに答えがあります。
- インストールできない、または起動するとすぐ落ちる場合は、システムのバージョンと端末の機種をサポートに伝えてください。たいていは機種かバージョンが合っていません。
