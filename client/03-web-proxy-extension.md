# 03 · Webプロキシ：ZeroOmega 拡張機能を 2 ステップで設定

> ウェブサイト版（より詳しい内容）：https://www.leotun.com/ja/guides/web-proxy?utm_source=github&utm_content=client-03

Webプロキシで経路を通るのは **このブラウザーだけ** で、システム上のほかのプログラムには影響しません。クライアントのインストールも管理者権限も不要で、「接続中」という状態がないため、仕組み上、接続が切れることもありません。会社のパソコン、すでに会社の VPN につながっているパソコン、ブラウザー 1 つだけを経路に通したい場合に向いています。いつ使うべきか、どんなときに VPN が必要かは「[ネットワークガイド 02](../network/02-choose-your-connection-method.md)」をご覧ください。

## 2 ステップ

1. **拡張機能を入れる**：Chrome / Edge / Firefox に ZeroOmega（SwitchyOmega の後継）をインストールします。各ブラウザー用のインストールリンクは[ウェブサイトのプロキシのページ](https://www.leotun.com/ja/httpproxy?utm_source=github&utm_content=client-03)にあります。
2. **読み込む**：ウェブサイトにログインし、プロキシのページで使いたい地域の国旗をクリックします（「全リージョンのインポートリンクをコピー」をクリックすれば、全地域を一度に読み込めます）。これで設定用のリンクがコピーされます。拡張機能の「Import/Export」（インポート / エクスポート）を開き、「Restore from online」（オンラインから復元）に貼り付けて「Restore」（復元）をクリックします。地域、アドレス、暗号化方式がまとめて読み込まれ、手で入力するものはありません。

あとは拡張機能のアイコンをクリックして地域を選び、ブラウザーに表示されるログイン画面でウェブサイトのアカウントとパスワードを入力します。地域を変えるときは、アイコンのメニューで別の地域をクリックします。経路を通さない通常の接続に戻すときは「Direct」（直接接続）に切り替えます。

## こんな場合は端末全体を通す方法を

- 動画・音楽アプリやプレーヤー：多くはブラウザーのプロキシを使わないので、「ページは開くのに動画が再生されない」ことになります。
- スマホのアプリ、ゲーム、デスクトップソフト。Dropbox などのソフトのプロキシ設定は暗号化なしの HTTP / SOCKS5 しか受け付けませんが、実際にはプロキシは暗号化されている必要があるため、当サイトの Webプロキシはそこには入力できません。代わりに Hiddify で端末全体を引き受けてください。「[10](10-app-proxy.md)」をご覧ください。
- 海外からテンセントビデオや iQIYI を見る：動画サイトは IPv6 と DNS もチェックしますが、Webプロキシはそこまでカバーしません。端末全体を通す VPN を使ってください。

## よくある質問

| 症状 | 原因 |
|---|---|
| ログイン画面が何度も表示される | アカウントの期限切れか、パスワードの誤り |
| 開くサイトと開かないサイトがある | 拡張機能の「auto switch」（自動切り替え）のルールで直接接続に回されています。一度グローバルプロキシモードで試してください |
| 中国では HTTPS のサイトしか開かない | 暗号化なしの HTTP は途中で書き換えられ、暗号化された接続だけが通ります。いまはほとんどのサイトが HTTPS です |
| 遅い | 地域を切り替えてください。プロキシと VPN は同じサーバー群を使っています |
