# クライアントガイド · インストールと設定

各接続方法の**インストールと接続**の手順をまとめています。Cisco AnyConnect、Hiddify、Webプロキシの拡張機能、OpenVPN、プライベートネットワーク（Tailscale）のほか、iOS でアプリをインストールできないときの対処、Telegram / Discord のインストール方法、複数の端末を一度で設定する方法、Dropbox などのソフトがプロキシを求めてきたときの対処も扱います。どの方法を選ぶかは「[どの接続方法がどんな場面に合うか](../network/02-choose-your-connection-method.md)」を、インストールしたのにつながらない場合は「[トラブルシューティング](../troubleshooting/)」をご覧ください。
