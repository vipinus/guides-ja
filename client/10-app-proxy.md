# 10 · Dropbox などのソフトが HTTP / SOCKS プロキシを求めてきたら

> ウェブサイト版（より詳しい内容）：https://www.leotun.com/ja/guides/app-proxy?utm_source=github&utm_content=client-10

**まず現状から：プロキシは暗号化が必須です。** 暗号化されていないプロキシ（素の HTTP、SOCKS4、SOCKS5）は中国のネットワークでは識別されて妨害され、しばらくすると遅くなったり切れたりするうえ、アカウントとパスワードも平文で流れます。長く使い続けられるのは暗号化された接続だけなので、当サイトの Webプロキシはすべて暗号化された接続を使っています。**HTTP / SOCKS5 しか受け付けないソフトには、Hiddify でマシン全体を引き受けさせてください**（下記参照）。

Dropbox、Telegram Desktop、Steam、クラウドストレージのクライアント、開発ツールといった単体のソフトはブラウザーの設定を読まず、ソフト自身のプロキシ設定は暗号化なしの HTTP / SOCKS5 しか受け付けません。両者がかみ合わないので、プロキシを入力してもつながりません。解決策は**プロキシを入力しないこと**です。Hiddify でパソコン全体を経路に通し、ソフトのプロキシ設定は「プロキシなし」にします。

## プロキシを入力してもつながらない理由

| 原因 | 説明 |
|---|---|
| 種類が合わない | ソフトが用意しているのは HTTP、SOCKS4、SOCKS5 だけで、どれも暗号化されていません。当サイトのプロキシは暗号化が必須なので入力できません |
| ネットで見つけた暗号化なしのプロキシ | しばらくはつながっても、やがて妨害され、つながったり切れたりするようになります |
| 通信の一部しか通らない | 多くのソフトはログインと同期だけがプロキシを使い、アップデート、通話、LAN 同期は直接つながったままです。HTTP プロキシはゲームや通話の UDP 通信をまったく転送しません |
| ソフトごとに個別に管理 | 地域やパスワードを変えるたびに 1 つずつ書き換える必要があり、1 つでも漏れるとそれが使えなくなります |

## おすすめの方法：Hiddify にマシン全体を引き受けさせる

1. 「[09 · Hiddify を全プラットフォームに入れる](09-hiddify-install-all-platforms.md)」に従って Hiddify をインストールし、「[02](02-singbox-subscription-links.md)」に従ってプロファイルを読み込みます。
2. 「VPN」モード（デフォルト）で接続します。Windows では初回の接続に管理者権限が必要です。
3. ソフトのプロキシ設定を「プロキシなし」に戻します。Dropbox は「基本設定 → ネットワーク → プロキシ」で「プロキシなし」か「自動検出」を選びます。Telegram Desktop は「設定 → 詳細設定 → 接続タイプ」で「プロキシを無効化」を選びます。プロキシの項目があるほかのソフトも、オフにしてください。
4. 確認：Dropbox のトレイアイコンが「最新の状態」になり、同期が始まります。ブラウザーで IP を表示するページを開き、出口が選んだ地域になっていることを確かめます。

「自動ルーティング」をオンにしておけば、Dropbox などの海外のサービスは経路を通り、WeChat、ネットバンキング、中国のサイトはいつもどおり直接つながります。

## よく使うソフト

| ソフト | 設定方法 |
|---|---|
| Dropbox | プロキシは「プロキシなし」か「自動検出」。「手動」でほかのアドレスを入れたままにすると、Hiddify をオフにしたときにオフラインのままになります |
| Telegram Desktop | 接続タイプは「プロキシを無効化」。内蔵の MTProto / SOCKS5 をトンネルの上に重ねても遅くなるだけです |
| OneDrive、Google Drive、iCloud（デスクトップ版） | システムのネットワークに従うので、設定は不要です |
| Steam、Epic、Battle.net | プロキシは不要です。ダウンロードが遅ければ、近い地域に切り替えてください |
| Zoom、Teams、Slack、Discord | 音声とビデオは UDP なので、マシン全体を通す方法でしか運べません |
| VS Code、JetBrains、Cursor | システムのネットワークに従います。ツール内で個別にプロキシを設定していたら消してください |

## クライアントをインストールできないとき（会社のパソコン）

- Dropbox やクラウドストレージはウェブ版を使います。[Webプロキシ](03-web-proxy-extension.md)を設定したブラウザーで dropbox.com を開けば、アップロードとダウンロードはできますが、自動同期はありません。
- コマンドラインツール（git、pip、npm、curl）は暗号化されたプロキシを受け付けます。Webプロキシのアドレスを `https_proxy` に入れてください。詳しくは「[中国から海外のサービスへ 05 · Linux とコマンドライン](https://github.com/vipinus/guides-zh-CN/blob/main/overseas-access/05-linux-server.md)」（中国語）をご覧ください。
- HTTP / SOCKS5 しか受け付けないそのほかのデスクトップソフトは、自分のパソコンやスマホで使うのがいちばんです。そのために会社のパソコンへマシン全体の VPN を入れるのはやめましょう。会社のセキュリティアラートが鳴ります。

## よくある質問

**SOCKS5 や HTTP のプロキシアドレスをもらえますか？** 当サイトのプロキシはすべて暗号化された接続です。暗号化されていないものは、すぐにつながったり切れたりするようになります。Hiddify にマシン全体を引き受けさせるほうが安定し、すべてのソフトを一度にカバーできます。

**Hiddify をオンにしたら、ソフトにもプロキシを入力すべきですか？** 不要です。入力すると二重に遠回りすることになり、よくて遅くなり、悪ければつながりません。

**スマホの Dropbox は？** スマホのアプリにはプロキシ設定がありません。Hiddify をインストールするか、Cisco（AnyConnect）を使えば、接続後はすべてのアプリが経路を通ります。

**Hiddify を使わない方法はありますか？** あります。Cisco、プライベートネットワーク、OpenVPN もマシン全体を引き受けるので、ソフトは同じく「プロキシなし」にします。Hiddify の利点は、振り分け機能を内蔵していることと、パケットロスの多いネットワークで速度が出やすいことです。
