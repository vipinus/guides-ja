# 04 · OpenVPN：.ovpn プロファイルをダウンロードして読み込み、接続する。ルーター・NAS・Linux でも使える

> ウェブサイト版（より詳しい内容）：https://www.leotun.com/ja/guides/openvpn-setup?utm_source=github&utm_content=client-04

OpenVPN は歴史のあるオープンソースのプロトコルで、ほぼすべての OS、ルーターのファームウェア、NAS にクライアントが入っています。LeoTun のプロファイルにはアカウント、パスワード、暗号化に必要な情報がすでに入っているので、読み込めばすぐに接続できます。スマホやパソコンで普段使うなら AnyConnect か Hiddify のほうが手軽で、OpenVPN が役立つのは **OpenVPN しか受け付けない場所**、つまり OpenWrt のルーター、Synology / QNAP の NAS、Linux サーバー、古い機器です。

## 3 つのステップ

1. [ウェブサイトの OpenVPN ページ](https://www.leotun.com/ja/openvpn?utm_source=github&utm_content=client-04)の表から、お使いのシステム用のクライアントをインストールします（どのプラットフォームにも公式の OpenVPN Connect があります。Windows なら OpenVPN GUI、macOS なら Tunnelblick も使えます）。
2. ログイン後、**地域の国旗をクリック**すると、その地域の .ovpn がダウンロードされます。1 地域につき 1 ファイルです。
3. クライアントでファイルを開いて接続します。

| プラットフォーム | 説明 |
|---|---|
| Windows / macOS / Android / iOS | プロファイルにアカウントとパスワードが入っているので、読み込んで接続するだけです |
| Linux | システムの VPN 設定 → ファイルからインポートし、初回接続時にウェブサイトのメールアドレスとパスワードを入力します。コマンドラインなら `openvpn --config file`。起動時に自動で立ち上げるなら `/etc/openvpn/client/` に置きます |
| OpenWrt ルーター | luci-app-openvpn をインストールし、.ovpn をアップロードして有効にします。当サイトのファームウェアがプリインストールされていれば不要です |
| Synology NAS | 「コントロールパネル」→「ネットワーク」→「ネットワークインターフェイス」→「作成」→「VPN プロファイルの作成」→ OpenVPN（.ovpn を読み込み）。NAS の外向きの通信を経路に通すなら「リモートネットワークでデフォルトゲートウェイを使用」（Use default gateway on remote network）にチェックを入れます |
| QNAP NAS | QVPN →「VPN クライアント」→「追加」→ OpenVPN で読み込みます |

## 中国にいる方へ：中国のサイトは直接接続に

接続すると、中国のサイトへの通信が遠回りになります。ウェブサイトに「中国直接接続ツール」があり、ダブルクリックで実行すると、中国の IP は直接、それ以外は経路を通るようになります。Cisco と OpenVPN のどちらでも使えます。中国国外にいる方は使わないでください。

## つながらないときは、この順に確認

| ログのキーワード / 症状 | 原因 | 対処 |
|---|---|---|
| AUTH_FAILED | アカウントかパスワードが違う、または期限切れ | ウェブサイトにログインして有効期限を確認します。パスワードを変えた場合は、プロファイルをダウンロードし直してください |
| 先に UDP がタイムアウトし、そのあと TCP でつながる | 今のネットワークが UDP を制限していて、自動で TCP に切り替わった | 使えますが遅くなります。遅すぎる場合はネットワークを変えるか、AnyConnect を使ってください |
| UDP でも TCP でも TLS handshake failed / key negotiation failed | サーバーまでのネットワーク経路が通じていない | 地域かネットワークを変えてください |
| 読み込み時にエラー | クライアントが古すぎる（OpenVPN 2.5 より前） | クライアントを更新してください |
| 接続中に突然切れる | アカウントの期限が切れ、サーバー側で切断された | 更新して接続し直してください。プロファイルを替える必要はありません |

## UDP か TCP か

両方とも使え、選ぶ必要はありません。プロファイルでは UDP が先に書かれているので、クライアントはまず UDP を試し、UDP が制限されていたりつながらなかったりすると、数秒後に自動で TCP に切り替えます。UDP は遅延が小さく速く、TCP はあくまで予備で、国をまたぐとはっきり遅くなります。UDP を常に制限しているネットワーク（一部の学内ネットワークや社内ネットワーク）では、最初から AnyConnect を使うことをおすすめします。

> 2026 年 9 月 15 日より前にダウンロードしたプロファイルは UDP のみです。自動切り替えを使いたい場合は、ダウンロードし直してください。

## セキュリティ

プロファイルにはアカウントとパスワードが入っているので、アカウントそのものと同じです。人に渡さないでください。漏れた場合は、ウェブサイトでパスワードを変更すれば、古いファイルはすぐに使えなくなります。ハンドシェイク自体も暗号化されていて、プロファイルの鍵がなければハンドシェイクを始めることすらできず、スキャンしてもサーバーは見えません。
