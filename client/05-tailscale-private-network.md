# 05 · プライベートネットワーク（Tailscale）：インストール、当サイトのコントロールサーバーへのログイン、出口の選択

> ウェブサイト版（より詳しい内容）：https://www.leotun.com/ja/guides/tailscale-mesh?utm_source=github&utm_content=client-05

「プライベート」の接続方法では Tailscale（WireGuard をもとにしたネットワークツール）を使います。LeoTun は自前のコントロールサーバーを運営しており、ログインには **当サイトのアカウント** を使います。Tailscale 公式のアカウントとは関係ありません。一度ログインすればつながったままで、出口の地域はメニューからいつでも変えられます。VPN との違いやどんな人に向いているかは「[ネットワークガイド 03](../network/03-private-network-vs-vpn.md)」をご覧ください。

## インストール

| プラットフォーム | 入手先 |
|---|---|
| Windows / macOS / Linux / Android | [ウェブサイトのプライベートネットワークのページ](https://www.leotun.com/ja/mesh?utm_source=github&utm_content=client-05)のダウンロード欄（当サイトから直接配布しているので、公式サイトに行く必要はありません） |
| iPhone / iPad | App Store。中国以外の地域の Apple ID が必要です（「[クライアント 06](06-ios-app-store.md)」を参照） |

## ログイン

1. **先に公式アカウントからログアウトする**（ログインしたことがある場合）：スマホではアバターをタップ →「Log Out」（ログアウト）、パソコンでは `tailscale logout` を実行します。完全にログアウトしないと、次のステップで必要な項目が表示されません。
2. **ログイン先を当サイトに向ける**：
   - スマホ：ログアウト状態の画面で右上の「⋯」→「Use custom server」（カスタムサーバーを使う。バージョンによっては「Use an alternate server」）をタップし、ウェブサイトのプライベートネットワークのページに書かれているアドレスを入力して「Log in」をタップします。
   - Windows / Linux：ウェブサイトのページから `tailscale up --login-server=…` のコマンドをコピーし、PowerShell / ターミナルで実行します。
   - macOS：**「Log in」はクリックしないでください**。Tailscale のウィンドウでアカウントの行の矢印 →「Account Settings…」→「Accounts」→「Add Account…」の横の小さな矢印 →「Add Account Using Alternate Server」（別のサーバーでアカウントを追加）を選び、アドレスを貼り付けて「Add Account…」をクリックします。
3. ブラウザーで当サイトのログインページが自動で開くので、当サイトのアカウントで確認します。クライアントに戻ると、すでにオンラインになっています。

## 出口を選ぶ

- スマホ：メニュー →「Exit Node」で地域を選びます。すぐに反映されます。
- パソコン：タスクトレイ / メニューバーのアイコン →「Exit Node」のサブメニュー。または `tailscale set --exit-node=<region-name>`（使える出口は `tailscale exit-node list` で確認できます）。
- 出口を使わないときは「None」（なし）を選びます（コマンドラインでは、イコールの後ろを空にします）。同時に使える出口は 1 つだけです。

## 有効期限と台数

- 端末のログインの有効期間はアカウントの期限日に連動し、期限が切れると数分以内にオフラインになります。更新したら、もう一度ログインするだけです。入れ直す必要はありません。
- 同時に接続できる台数はプランで決まり（個人 2 台、ファミリー 4 台、ビジネス 8 台）、ほかの接続方法と枠を共有します。プランの上限を超えるときは、一時的にアカウントタイプを上げ（残り期間は料金に応じて同じ価値で換算されます）、用が済んだら戻せます。

## ほかの方法が向いている 2 つのケース

- 同じ端末でほかの VPN（会社の AnyConnect、ほかのメッシュネットワークソフト）を動かしている：DNS と経路を取り合います。中国の動画を見ると著作権の表示が出る、会社のイントラネットが開かない、といった現象の原因はこれです。
- UDP を制限している学内 / 社内ネットワーク：WireGuard は UDP で動くので、Tailscale のリレー経由でしかつながらず、とても遅くなります。AnyConnect に切り替えてください。
