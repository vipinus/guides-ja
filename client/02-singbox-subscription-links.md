# 02 · サブスクリプションリンクの読み込み方（Hiddify、Clash、Shadowrocket）

> ウェブサイト版（より詳しい内容）：https://www.leotun.com/ja/guides/singbox-subscription?utm_source=github&utm_content=client-02

プロキシ回線業者が渡してくる「サブスクリプションリンク」は、クライアントが完全な設定をダウンロードするための HTTPS のアドレスにすぎません。サーバー、ポート、認証情報がすべて入っているので、手で入力するものはありません。LeoTun の Hiddify のページでも同じ種類のものを渡していますが、最初から 3 つの形式で用意しているので、Hiddify、Clash、Shadowrocket がそれぞれ自分用のものを使え、変換は一切不要です。

## ポップアップの 3 つのボタン

ウェブサイトにログイン → Hiddify のページ → 地域の国旗をクリックします。QR コードがポップアップで表示され、その下にボタンが 3 つあります。ボタンは OS 別ではなく **サブスクリプションの種類別** に分かれているので、スマホでもパソコンでも同じものが表示されます。

| ボタンに書かれているクライアント | サブタイトル | クリックでコピーされるもの |
|---|---|---|
| Hiddify / sing-box / GUI.for.SingBox / Karing | sing-box サブスクリプション | スマホでは、アプリを起動する `sing-box://import-remote-profile?url=…` のインポートリンク。パソコンでは、貼り付け用の普通の `https://…` 設定 URL。設定には振り分けのルールと IPv6 を拒否するルールがすでに入っているので、「サブスクリプションテンプレート」でくるむ必要はありません |
| Clash Meta / Clash Verge / FlClash / Stash / Mihomo Party / Clash Nyanpasu / ClashX Meta / OpenClash | Clash サブスクリプション | Clash 形式（YAML）のサブスクリプション URL。クライアントのサブスクリプション / プロファイル一覧に貼り付けます |
| NekoBox / Shadowrocket / v2rayN / v2rayNG / Streisand / V2Box / Loon / Egern / Husi / NekoRay / Pharos Pro / Bedlam / Furious / daed / Lumen KVN / Kitty Pro | 共有リンク | `hysteria2://…` の 1 行。ノードの情報だけで、振り分けのルールは入っていません |

- 名前が 1 行に収まらないときはループでスクロールします。異常ではありません。
- **ボタンをクリックすると、上の QR コードもその種類に切り替わる** ので、対応するクライアントで読み取れます。ポップアップを開いた直後の QR コードは Hiddify / sing-box 用で、ほかのクライアントでそのまま読み取ると「無効な QR コード」になります。先に自分のクライアントのボタンをクリックしてから、読み取るか貼り付けてください。
- ページ上部の「全地域を一括インポート・自動選択」のポップアップには最初の 2 つのボタンだけがあり、共有リンクはありません。

**サブスクリプション変換**：ある形式を別の形式に変換する第三者のサイトのことです。LeoTun は 3 つの形式を最初から用意しているので、**変換は不要です**。認証情報を含むリンクを変換サイトに渡すのは、アカウントを第三者に渡すのと同じなので、やめてください。

## Hiddify / sing-box 系：1 つ目のボタン

1. Hiddify をインストールします（Android：ウェブサイトのダウンロードページか Google Play、iOS：App Store、デスクトップ版は Windows / macOS / Linux に対応）。sing-box のコアが組み込まれています。
2. 地域の国旗をクリックすると、QR コードがポップアップで表示されます。
3. スマホ：1 つ目のボタンをタップして Hiddify に切り替えると、クリップボードから追加するよう案内されます。または別の端末の Hiddify で「QR コードをスキャン」を使います。パソコン：同じボタンをクリックすると https:// のアドレスがコピーされるので、Hiddify で「+」→「クリップボードから追加」を選んで保存します。
4. 接続をタップし、初回は VPN の許可を承認します。地域を増やすときは別の国旗をクリックします。地域ごとに別のプロファイルになります。

## Clash 系：2 つ目のボタン

Clash Meta（mihomo）、Clash Verge、FlClash、Stash などは、「Clash サブスクリプション」のボタンをクリックし、コピーされた URL をクライアントのサブスクリプション / プロファイル一覧に貼り付けます。サブスクリプション変換ツールは不要です。

**Clash 系のクライアントでは共有リンクを使わないでください**。`hysteria2://` の 1 行をプロファイルとして読み込むことはできません。

## そのほかのクライアント：3 つ目のボタン

「共有リンク」のボタンをクリックし、NekoBox / Shadowrocket / v2rayN / v2rayNG などで「クリップボードからインポート」を使うか、ボタンをクリックしたあとで上の QR コードを読み取ります。共有リンクにはルールが入っていないので、振り分けと IPv6 は自分で設定する必要があります。海外にいて中国のコンテンツを見たいなら、中国のドメインをノード経由にし、IPv6 をオフにしてください。

ボタンで v2rayN より後ろに並んでいるクライアントはどれも hysteria2 に対応していますが、共有リンクは hysteria2 の拡張形式を使っているため、一部のクライアントは解析できません。読み込みに失敗する、つながらないという場合は、Hiddify に切り替えてください。

## 使えないクライアント

| クライアント | 理由 |
|---|---|
| Surge | hysteria2 には対応しているが、独自の設定形式しか読めないため、3 種類のどれも合わない |
| Quantumult X | この種の回線に対応していない |
| 初代の Clash、Clash for Windows | コアが hysteria2 に対応していない。mihomo コアのクライアントを使ってください |

## サブスクリプションに期限はある？

- **時間がたっても期限切れにはなりません。** サブスクリプション URL のトークンはアカウントに結び付いていて、アカウントが有効なあいだはずっと使えます。更新やプラン変更をしても、読み込み直す必要はありません。
- **パスワードを変えると、古い URL はすぐに無効になります。** スマホをなくしたときやリンクが漏れたときは、これで利用権を取り消せます。変えたあとは、もう一度 QR コードを読み取ってください。
- **アカウントの期限が切れると**、URL は 401 を返します。更新すれば、今あるプロファイルを入れ替える必要はありません。
- **2026 年 9 月より前に読み込んだプロファイル** には IPv6 を拒否するルールがありません。削除して読み込み直してください。

読み込んだのにつながらない場合は「[トラブルシューティング 04](../troubleshooting/04-singbox-import-not-connecting.md)」をご覧ください。

## よくある質問

**Hiddify のサブスクリプションと Clash のサブスクリプションの違いは？** 形式（JSON と YAML）が違い、それぞれのクライアントは相手のサブスクリプションを認識しませんが、ノードそのものはどちらでも使えます。LeoTun は両方を直接用意しています。Clash 系のクライアントは「Clash サブスクリプション」のボタンをクリックし、共有リンクは使わないでください。

**1 つのプロファイルに全地域を入れられますか？** 国旗から読み込むと地域ごとに 1 つのプロファイルになり、クライアントのプロファイル一覧で切り替えます。こうしておけば、ある地域のアドレスが変わっても影響はその地域だけです。中国以外の全地域を一度に読み込んでクライアントに自動で選ばせたい場合は、ページ上部の「全地域を一括インポート・自動選択」をクリックしてください（sing-box サブスクリプションと Clash サブスクリプションのボタンだけがあります）。

**QR コードを家族に送ってもいいですか？** QR コードにはアカウントの認証情報が入っていて、送った相手はあなたのアカウントを使えるようになります。家族との共有はかまいません（同時接続の台数はプランで決まり、個人 2 台、ファミリー 4 台、ビジネス 8 台）が、公開の場所には載せないでください。漏れたらパスワードを変えれば無効になります。
