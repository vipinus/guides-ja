# 03 · プライベートネットワーク（Tailscale）と VPN の違い、使いどころ

> ウェブサイト版（より詳しい内容）：https://www.leotun.com/ja/guides/tailscale-mesh?utm_source=github&utm_content=network-03

プライベートネットワークで使っているのは Tailscale という、WireGuard をベースにしたネットワークツールです。コントロールサーバーは LeoTun が自前で運用しており、当サイトのアカウントでログインします。AnyConnect や OpenVPN のような「接続型」の VPN とは別のものです。

## 3 つの違い

| | 接続型 VPN（AnyConnect / OpenVPN / Hiddify） | プライベートネットワーク（Tailscale） |
|---|---|---|
| 接続 | 毎回接続をタップし、切れたらつなぎ直す | 一度ログインすればオンラインのまま。ネットワークが変わっても自動で復帰 |
| 出口 | つないだらすべての通信が出口を通る | 出口は任意。選ばなければインターネット向けの通信は手元の回線からそのまま出ていき、暗号化されるのはプライベートネットワーク内の端末同士の通信だけ。地域の出口を選んだときに初めて VPN と同じになる |
| 端末同士のアクセス | なし | 同じアカウントのスマホ、パソコン、NAS が直接つながる。ポート開放もグローバル IP も不要 |

## 向いている場面

- 端末が複数あり、一度設定したらずっとオンラインにしておきたい。
- 自宅の NAS、パソコン、カメラに外からアクセスしたい：両方でプライベートネットワークにログインすれば、同じ LAN にいるように端末名で直接つながります。
- 長時間つなぎっぱなしにしたい端末：セッションのタイムアウトがありません。

## ほかの方法が向いている場面

- 一時的に一度使うだけ：Hiddify を QR コードで読み込むか、AnyConnect を入れるほうが早いです。
- 端末で会社の VPN やほかのネットワークソフトがすでに動いている：DNS と経路を取り合ってしまい、中国の動画を見ると著作権の表示が出る、社内ネットワークが開かない、といった症状が出ます。Webプロキシのようにブラウザーだけに影響する方法を使ってください。
- UDP を制限している学内・社内ネットワーク：WireGuard は UDP で動くため、リレー頼みになって遅くなります。AnyConnect に切り替えてください。

## 有効期限と台数

端末のログインの有効期間はアカウントの期限日に従います。期限が切れると数分以内にオフラインになり、更新したらもう一度ログインするだけです。同時にオンラインにできる台数はプランで決まり（個人 2 台、ファミリー 4 台、ビジネス 8 台）、ほかの接続方法と枠を共有します。同時接続がプランの上限を超えるときは、一時的にアカウントタイプを上げ（残り期間は料金に応じて同じ価値で換算されます）、用が済んだら戻せます。
