# 01 · 海外から中国のサービスにアクセスする仕組み

## よくある症状

海外で iQIYI、bilibili、NetEase Cloud Music を開くと「このコンテンツは中国本土でのみご利用いただけます」と表示される。ネットバンキングや 12306（中国鉄道の予約サイト）がまったく開かない、または認証コードが届かない。

## 原因は 1 つ：IP の登録地

端末がインターネットにつながると、通信事業者からグローバル IP アドレスが割り当てられます。こうしたアドレスには世界共通の台帳があり、それぞれがどの国のどの事業者のものかがわかるようになっています。中国の動画・音楽プラットフォームは**中国本土**向けの配信権しか買っておらず、法的にも国外へ配信できないため、海外の IP を見た時点で拒否します。

銀行やチケット予約サイトの理屈は違います。こちらは著作権ではなくリスク管理の問題で、海外の IP からのログインは高リスクとみなされ、そのままブロックされます。

## 解決の考え方

サーバーから見える IP を中国本土のものにします。そのためには、通信をいったん中国本土にあるサーバーに送り、そのサーバーが代わりに目的のサイトにアクセスします。目的のサイトにはそのサーバーの IP が見えるので、通してもらえます。

これが「中国向けの経路」の役割です。あなたの通信を中国本土の IP から送り出します。

## よくある 3 つの誤解

- **DNS を変えても解決しません。** DNS はドメイン名をアドレスに変換するだけで、目的のサイトが見るのはあなたの接続元の IP であり、使っている DNS ではありません。
- **システムの地域も見るプラットフォームがあります。** 一部のプラットフォームは IP のほかに、端末の言語やアプリストアの地域も確認します。その場合はシステムの地域も変更してください。
- **速度は 2 地点を結ぶ経路の品質で決まります。** 海外から中国本土への国際回線がボトルネックなので、サーバー自体の性能より、自分に近くて中国本土への回線が最適化された入口を選ぶほうが重要です。
