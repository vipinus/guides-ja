# 06 · 中国サーバーのゲームとライブ配信

## ゲーム：ログインはできるが、遅延が大きい

中国サーバーのゲームの多くは、海外の IP をブロックしていません。問題は遅延です。ヨーロッパや北米にいる場合、中国のサーバーまでの物理的な距離だけで一定の遅延が生じ、さらに国境をまたぐ回線の揺らぎ（ジッター）やパケットロスが重なって、カクつきや切断として現れます。

いわゆる「ゲーム用の高速化」がしていることは、通信をより質のよい回線で中国まで届け、遠回りとパケットロスを減らすことです。揺らぎが大きくパケットが落ちる接続を安定した接続に変えるもので、多くのゲームではそれが「遊べる」か「遊べない」かの分かれ目になります。

## 接続先の選び方

選ぶ地域は通信が着地する国です。中国サーバーのゲームなら **中国の地域** を選べば、出ていくのは中国の IP になります。ドイツやフランスなど UDP を通さない地域は選ばないでください。そうした地域ではゲームはまずつながりません。いくつか試して、ゲーム内に表示される遅延（ping）で判断してください。

## プロトコルの選び方

ゲームはパケットロスに敏感なので、UDP で動くプロトコルを優先し、UDP に対応していない地域は避けてください。TCP 系のプロトコルはパケットが落ちると再送するため、遅延が大きく跳ね上がります。

## ライブ配信

抖音（Douyin）、快手（Kuaishou）、闘魚（Douyu）、虎牙（Huya）は、海外 IP への制限のかけ方がそれぞれ違います。多くは視聴できますが、画質が制限されます。中国の IP に切り替えると、すべての画質を選べるようになります。ライブ配信は高いビットレートの通信が続くので、帯域に余裕のある接続先を選んでください。

## 実名認証

中国サーバーのゲームでは実名認証が求められます。これはアカウント単位の要件で IP とは関係がなく、IP を変えても解決しません。
