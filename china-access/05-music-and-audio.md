# 05 · 音楽、ポッドキャスト、オーディオブック

## よくある症状

NetEase Cloud Music（網易雲音楽）、QQ 音楽、Kugou（酷狗音楽）で大量の曲がグレーアウトし、「権利者の要請により、お住まいの地域では現在再生できません」と表示される。Ximalaya（喜馬拉雅）や Qingting FM（蜻蜓FM）の一部のコンテンツも同じです。

## 原因

動画と同じく地域ごとの権利の問題で、確認されるのは IP だけです。中国の IP に切り替えてからリストを更新すれば、グレーアウトしていた曲はすぐに戻ります。

## プラットフォームごとの注意点

| プラットフォーム | 注意点 |
|---|---|
| NetEase Cloud Music | IP の判定がいちばん厳しい一方、IP を変えたあとの曲のそろい方もいちばん充実しています |
| QQ 音楽 | 一部の曲は会員登録が必要で、これは IP の問題ではありません |
| Kugou / Kuwo（酷我音楽） | IP を変えるだけで十分です |
| Ximalaya | 一部の有料アルバムには地域制限があります |

## ダウンロード済みの曲

アプリによってはローカルのキャッシュにも地域チェックをかけるので、IP を変える前にダウンロードした曲もグレーアウトすることがあります。IP を変えたあとにアプリを開き直せば十分で、ダウンロードし直す必要はありません。

## 手間のかからない方法

音楽は通信量が少ないので、**Webプロキシ**やブラウザーで使う方法で十分で、端末全体を経路に通す必要はありません。スマホなら、音楽アプリだけを経路に通し（アプリ単位のプロキシ）、ほかのアプリは現地のネットワークのままにすることもでき、通信量もバッテリーも節約できます。
