# 09 · 届かない認証コードと中国の電話番号

## 起きること

行政サービス、銀行、12306（中国鉄道の予約サイト）、各種アプリの SMS 認証コードがスマホに送れない、または送信されたのにいつまでも届かない。

## 原因

SMS の認証コードは中国の電話番号にしか送られません。海外にいると、中国の SIM カードを持ってきていない、持ってきたけれど国際ローミングをオンにしていない、料金未払いで利用停止になっている、のどれかです。これは IP とは関係がなく、中国の IP に切り替えても SMS の問題は解決しません。

## 解決法

1. **中国の SIM カードを残しておき**、出国前に国際ローミングを有効にして、番号保持用のプランを選びます。たいていのキャリアでは、海外での SMS 受信は無料かほぼ無料です。
2. **デュアル SIM のスマホ**：中国のカードは SMS の受信専用、現地のカードはデータ通信用にして、2 枚を同時に入れておきます。
3. **eSIM**：中国の番号を eSIM に切り替えられるキャリアもあり、eSIM 対応のスマホなら SIM スロットを使わずに入れられます。
4. **仮想番号は当てにならない**：ネットで借りる認証コード受信用の番号は、プラットフォームのブラックリストに入っていることがよくあります。行政サービスや銀行の登録には絶対に使わないでください。

## 届いたのに認証に失敗する

- 認証コードの有効期間は短く、たいてい 5 分です。届いたらすぐ入力してください。
- 1 日に何度も認証コードを要求すると、回数制限がかかります。1 時間待ってから試してください。
- 顔認証の失敗は、たいていアプリのバージョンかカメラの権限の問題です。アプリの中国版を入れ、カメラを許可してください。
