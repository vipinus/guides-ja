# 04 · ネットバンキング、モバイルバンキング、決済

## 銀行のリスク管理が見ているもの

銀行が見ているのは IP だけではありません。いくつもの手がかりを組み合わせて点数をつけています。

1. **IP の登録地**：海外の IP だと、それだけでリスクの段階が上がります。
2. **SIM カード**：モバイルバンキングのアプリは SIM の情報を読み取り、海外のキャリアのカードだとマイナスに働きます。
3. **端末の指紋**：新しい端末や、脱獄・root 化した端末。
4. **行動**：新しい場所から初めてログインして、いきなり高額の送金をする。

そのため、よくあるのが「中国の IP に切り替えたらログインはできたのに、送金はやはり止められる」という状況です。IP で解決できるのは 1 つ目だけです。

## できること

- 中国の IP に切り替えたら、**まず少額の取引から**始めてリスク管理をこの環境に慣れさせ、そのあとで高額の取引をします。
- 中国の SIM カードを残しておき、ローミングをオンにします。認証コードも SIM のチェックも、これに頼っています。
- モバイルバンキングのアプリは、できるだけ中国版を入れてください。ストアの国・地域の問題は「[iOS でアプリをインストールできないとき](../client/06-ios-app-store.md)」をご覧ください。
- 止められたら、何度もやり直さないでください。失敗を繰り返すと一時的に凍結されます。解除にはカスタマーサービスに電話するのがいちばん早い方法です。

## Alipay と WeChat Pay

どちらも銀行より IP に寛容で、海外の IP からでもたいてい使えますが、海外のカードを紐付けたアカウントには金額や利用先の制限があります。中国のカードで支払う必要があるときや、中国の店舗に送金するときは、中国の IP に切り替えたほうがずっとスムーズです。

## やってはいけないこと

経路を通していてもいなくても、公衆 Wi-Fi でネットバンキングを使わないでください。経路は出口の IP を変えるだけで、銀行の先まで暗号化してくれるわけではありません。安全性を支えているのは、銀行アプリ自身の暗号化です。
