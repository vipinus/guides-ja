# 01 · 中国の IP が必要なサービス

判断の基準は 1 つだけです。サービスから見てあなたの接続元の IP が中国本土にない場合、利用を拒否されるか、機能が制限されます。下の表は、制限の厳しさの順に並べています。

| 分類 | 例 | 中国の IP がないとどうなるか | IP のほかに確認されるもの |
|---|---|---|---|
| 動画 | iQIYI（愛奇芸）、テンセントビデオ、Youku（優酷）、Mango TV、bilibili の一部のアニメ | 中国本土限定と表示される、または無料コンテンツしか見られない | アプリストアの地域、アカウントの登録地 |
| 音楽 | NetEase Cloud Music（網易雲音楽）、QQ 音楽、Kugou（酷狗音楽） | 大量の曲がグレーアウトして再生できない | なし |
| 行政サービス | 国家政務サービスプラットフォーム、各省の行政サービスサイト、税務、社会保険、住宅積立金 | ページが開かない、または認証コードが届かない | 電話番号、顔認証 |
| 教育 | 学信網（CHSI）、学位認証サイト、大学の教務システム | 開かない、または極端に遅い | なし |
| 交通 | 12306（中国鉄道の予約サイト）、航空会社のサイト | 開かない、支払いに失敗する | 電話番号、支払い手段 |
| 金融 | ネットバンキング、モバイルバンキング、Alipay、WeChat Pay | ログインがリスク管理で止められる、送金に失敗する | SIM カード、端末の識別情報、顔認証 |
| ゲーム | 中国サーバーの PC ゲームやスマホゲーム | ログインはできるが、遅延が大きく切断される | 実名認証 |
| 生活サービス | Meituan（美団）、Ele.me（餓了麼）、DiDi、タオバオの一部の機能 | 位置情報がおかしくなる、注文に失敗する | 位置情報、電話番号 |
| ライブ配信 | Douyin（抖音）、Kuaishou（快手）、Douyu（斗魚） | 一部の地域では視聴できない | なし |

## 大事な区別

**「中国の IP が必要」と「中国の電話番号が必要」は別のことです。** 動画と音楽は IP しか見ないので、IP を変えるだけで十分です。行政サービス、銀行、チケット予約は、IP のほかに SMS の認証コードを受け取り、顔認証を通る必要があります。IP で解決するのは「開けるかどうか」で、その先の認証はご自身の中国の電話番号と身分証明書次第です。

## IP の問題を解決する方法

通信をいったん中国本土のサーバーに送り、そのサーバーが代わりに目的地にアクセスします。方法はクライアント、Webプロキシ、ルーターの 3 つです。選び方は、姉妹リポジトリの「[どの接続方法がどんな場面に合うか](../network/02-choose-your-connection-method.md)」をご覧ください。
