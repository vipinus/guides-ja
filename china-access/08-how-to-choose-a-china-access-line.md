# 08 · 中国向けの経路の選び方：中国の IP はどこから来るのか、無料のものはどこでつまずくのか

> ウェブサイト版（より詳しい内容）：https://www.leotun.com/ja/guides/choose-china-vpn?utm_source=github&utm_content=china-access-08

中国向けの経路がすることは 1 つだけです。海外から送ったリクエストを、**中国本土** の IP からテンセントビデオ、NetEase Cloud Music、ネットバンキングに届くようにすることです。ですから、まず 2 点を見てください。出口が本当に中国本土の IP か、そして端末の通信のどこかが経路を素通りしていないか。速度、料金、クライアントはそのあとです。

## 中国の IP はどこから来るのか

事業者は中国本土に自前のサーバーを持っている必要があります。中国国内のクラウド事業者では、マシンを立ち上げるのに実名登録が必要で、帯域も使った分だけ課金されるので、コストは海外のマシンよりはるかに高くなります。まともな中国向けサービスがほぼすべて有料で、中国の出口の数が限られているのはそのためです。

よくある代用品は、香港、台湾、日本のマシンを「中国向け」と称するものです。こうしたアドレスは bilibili の香港・マカオ・台湾向けの一部のコーナーでは使えますが、テンセントビデオ、iQIYI、Youku では著作権による制限が表示されたままで、ネットバンキングや 12306 でも海外扱いになります。**見分け方：つないだあとに IP の登録地を調べ、「中国・〇〇省」と表示されて初めて合格です。**

## 選ぶ前に確認する 5 項目

| 項目 | 確認方法 | 不合格の例 |
|---|---|---|
| 出口の地域 | つないだあとに IP の登録地を調べる | 香港、台湾、日本、韓国のアドレス |
| IPv6 と DNS | 「test ipv6」で検索してテストページを開く | IPv6 の欄に今いる国が表示される → 動画サイトにはやはりブロックされます。「[トラブルシューティング 03](../troubleshooting/03-ipv6-and-dns-leak.md)」を参照 |
| クライアント | 標準のプロトコル（AnyConnect、OpenVPN、Hiddify）かどうか | 独自アプリが 1 つあるだけで、それが配信停止になると使えるものがなくなる |
| 帯域 | 北京時間の夜 8 時から 11 時に 1080p を再生する | 昼間は速いのに、夜は読み込みが終わらない |
| 複数台とルーター | 1 アカウントで何台使えるか、ルーターで家じゅうをつなげるか | 端末ごとに別々に買う必要がある |

## 無料の中国向け経路がすぐ切れる理由

問題は「無料」そのものではなく、コストの構造です。中国本土の出口の帯域は従量課金なので、無料のサービスは 3 つのうち 1 つを選ぶしかありません。1 台のマシンに数千人を詰め込んでピーク時に全員がカクつくか、通信量や時間に上限を設けて途中で支払いを促す画面を出すか、広告の埋め込み、閲覧履歴の収集、あなたの端末を他人の出口として使うといった別の方法で稼ぐかです。

無料の「中国向け」ブラウザー拡張機能には、もう 1 つ死角があります。プロキシするのはブラウザーのウェブリクエストだけで、動画プレーヤー、アプリ、システムの DNS は通らないので、「ページは開くのに動画が再生されない」がよく起きるのです。

たまに何かを調べる程度なら、無料で十分です。ドラマを追いかける、音楽を聴く、ネットバンキングを使うなら、安定した有料の経路で節約できる時間は、利用料よりずっと価値があります。まず 4 時間のトライアルを受け取り、夜のピーク時に一度試してから決めてください。

## 留学生、旅行者、家族、それぞれの設定

- **留学生**：寮のネットワークはたいてい IPv6 があるので、IPv6 を遮断するクライアントを使ってください。ネットバンキング、学信網（CHSI）、12306 には、必要なときだけ中国向けの経路につなぎ、用が済んだら切断すると、アカウントが不正アクセス対策に引っかかりにくくなります。
- **短期の旅行**：スマホに Cisco か Hiddify のクライアントを入れ、QR コードを読み取って読み込めば、着いたその場で使えます。
- **海外に長く暮らす家族全員**：ファームウェアを書き込んだルーターを 1 台経路につなげば、テレビ、セットトップボックス、高齢の家族のスマホは設定不要です。「[ルーターで中国の動画サイトを見られるようにする](../router/06-unlock-chinese-video-with-router.md)」をご覧ください。

## 5 分でできるセルフチェック

1. 中国向けの経路につなぐと、IP の検索結果に中国本土の省が表示される。
2. IPv6 のテストページで、IPv6 が使えないと表示されるか、やはり中国本土のアドレスと表示される。
3. テンセントビデオで中国限定配信のドラマを適当に開くと、再生できる。
4. 北京時間の夜 8 時以降に 1080p をもう一度再生すると、何度も読み込みで止まったりしない。
5. 別の中国の出口に切り替えて、最初の 3 つのステップを繰り返す。

## よくある質問

**中国向けの VPN と、中国向けの「加速器」に違いはありますか？** 本質的な違いはありません。「加速器」はたいていゲームや動画の会社がカスタマイズしたアプリで、特定のアプリだけを対象にします。VPN は端末全体のトンネルです。

**香港のノードでテンセントビデオを見られますか？** 見られません。配信権は中国本土だけが対象です。

**1 つのアカウントで何台使えますか？** LeoTun では同時接続の台数はプランで決まります。個人 2 台、ファミリー 4 台、ビジネス 8 台です。ルーターは 1 台と数え、その配下の端末は別に数えません。プランの上限より多くの台数を同時につなぐときは、一時的にアカウントタイプを上げ（残り期間は料金に応じて同じ価値で換算されます）、あとで戻せます。

**Clash は使えますか？** 使えます。LeoTun では sing-box サブスクリプション、Clash サブスクリプション、hysteria2 の共有リンクを用意しています。Clash Meta、Clash Verge、FlClash、Stash などなら、「Clash サブスクリプション」のボタンをクリックして URL をクライアントのサブスクリプション一覧に貼り付けます。サブスクリプション変換ツールは不要で、共有リンクは使わないでください。初代の Clash と Clash for Windows はコアが hysteria2 に対応していないため使えません。このサブスクリプションは初期設定でローカルネットワーク以外のすべてをノード経由にするので、中国の動画のために変更するものはありません。自分でルールを追加する場合は、中国のドメインを「direct」（直接）にしないでください。
