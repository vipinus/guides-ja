# 03 · 中国の行政・公共サービスのサイトを使う

## よくある症状

国家政務サービスプラットフォーム、各省・市の行政サービスサイト、電子税務局、社会保険や住宅積立金（住房公積金）の照会、学信網（CHSI、学歴認証のサイト）、12306（中国鉄道の予約サイト）。海外からだと、そもそも開かないか、開いても認証コードが届かない、顔認証が通らない、ということが起こります。

## まず、どの段階の問題かを見極める

| 症状 | 原因 | 対処 |
|---|---|---|
| ページがまったく開かない、またはタイムアウトする | サイトが中国本土の IP にしか開放されていない、または国境をまたぐ回線でパケットが落とされている | 中国の IP に切り替える |
| 開くが、携帯の認証コードが届かない | SMS は中国の電話番号にしか送られない | 中国の SIM カードを残しておき、国際ローミングをオンにして SMS を受け取る |
| 認証コードは届くが、顔認証が通らない | 海外のアプリストアで入れたバージョンを使っている、またはカメラの権限 | 中国版のアプリを入れ、カメラを許可する |
| 「現在のネットワーク環境に異常があります」と表示される | 不正アクセス対策の仕組みにプロキシの特徴を検知された | 別の接続先の地域で試す、またはルーターを使う（家庭の光回線に近く見えます） |

## 12306 は別格

12306 は IP にきわめて敏感で、海外の IP ではトップページすら開かないことがあります。中国の IP に切り替えたうえで、登録には中国の電話番号、切符の購入には実名の身分証、支払いには中国の銀行カードか Alipay が必要です。3 つそろって初めて切符を買えます。帰省ラッシュなどの争奪戦のピーク時には 1 つの IP からのリクエスト頻度も制限されるので、ウィンドウをいくつも開いて更新し続けるのはやめてください。

## 学信網（CHSI）と学歴認証

学信網そのものは海外の IP にそれほど厳しくなく、主な問題は遅さです。ただし、ここの認証 SMS もやはり中国の番号にしか送られません。留学中の方は、学歴認証の手続きをする前に、中国の電話番号がまだ SMS を受け取れるかを確認しておいてください。

## ひとつ提案

行政関係の手続きは年に 1〜2 回しか発生しないことが多く、そのたびに直前で経路を探すのはかなりの手間です。中国向けの経路を決まった接続先として 1 つ設定しておき、用が済んだら切り替えて戻すほうが、毎回設定し直すより楽です。
