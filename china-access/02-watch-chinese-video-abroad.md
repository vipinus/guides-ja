# 02 · 海外から中国の動画を見る

> ウェブサイト版（より詳しい内容）：https://www.leotun.com/ja/guides/overseas-video?utm_source=github&utm_content=china-access-02

## なぜ見られないのか

各プラットフォームは中国本土向けの配信権しか買っておらず、海外の IP は一律でブロックされます。技術的な不具合ではなく、IP を変えるしか解決法はありません。

## プラットフォームごとの違い

| プラットフォーム | ウェブ版 | アプリ | 補足 |
|---|---|---|---|
| iQIYI（爱奇艺） | IP を変えれば見られる | IP を変えれば見られる | 海外版の「iQIYI」は別のアプリでコンテンツが少ない。間違えて入れないように |
| テンセントビデオ | IP を変えれば見られる | IP を変えれば見られる | 海外版の WeTV も同様 |
| Youku | IP を変えれば見られる | IP を変えれば見られる | |
| Mango TV | IP を変えれば見られる | IP を変えれば見られる | |
| bilibili | ほとんどのコンテンツはそのまま見られる | 同じ | 一部のアニメやドキュメンタリーだけ地域制限がある |
| 央視頻 / CCTV | IP を変えれば見られる | 同じ | ライブチャンネルがいちばん IP に敏感 |

**海外版アプリの落とし穴**：海外のストアで iQIYI の中国語名（爱奇艺）を検索すると、たいてい iQIYI の国際版が出てきますが、コンテンツのラインナップはまったく別物です。中国のラインナップを見るには中国版のアプリを入れる必要があります。iPhone は中国の地域の Apple ID が必要で、Android は APK を直接インストールできます。

## つながっているのに、まだ著作権の制限と言われる

出口の IP がすでに中国本土なのに著作権の制限が表示されるなら、十中八九、端末の **IPv6 か手元の DNS が経路を迂回しています**。2026 年 9 月から、LeoTun の端末全体をカバーする 3 つの接続方法は経路側で IPv6 をブロックしています。9 月より前に読み込んだ Hiddify の設定は、削除してから QR コードを読み取って読み込み直してください。切り分けの手順は「[すり抜けているのは IPv6 と DNS](../troubleshooting/03-ipv6-and-dns-leak.md)」をご覧ください。

## テレビで見る

テレビやセットトップボックスにはクライアントを入れられないので、方法は 2 つです。

1. **ルーターを使う方法**：中国向けの経路をルーターに設定して振り分けをオンにすれば、テレビはその Wi-Fi につなぐだけで見られます。家族全員が恩恵を受けます。「[高齢の家族とテレビのために](../router/04-family-tv-and-router.md)」をご覧ください。
2. **画面キャスト**：スマホで中国向けの経路をオンにして、テレビにキャストします。簡単ですが、スマホはずっとつけたままにしておく必要があります。

## 画質

1080p には安定して 5 Mbps 以上が必要です。夜のピーク時に再生がカクつくなら、緑のランプの地域を選ぶか、接続方法を切り替えてください。それでもカクつくなら、たいていは手元のブロードバンドが原因です。プラットフォームを変えるより、近くて中国本土への回線が最適化された入口を選ぶほうが効果があります。
