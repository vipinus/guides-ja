# 海外から中国へ · 中国の IP が必要なものすべて

海外にいると、多くの中国のサービスが「IP が中国本土にない」という理由で利用を拒否します。動画、音楽、行政サービス、銀行、チケット予約、ゲームなどです。場面ごとに 1 記事ずつ、**なぜブロックされるのか、どう解決するか、ほかにどんな落とし穴があるか**をはっきり説明します。

**いちばん読まれている記事：[ルーターで海外から中国の動画サイトを見られるようにする](../router/06-unlock-chinese-video-with-router.md)**。テレビ、セットトップボックス、家じゅうの端末を一度で設定でき、Wi-Fi につなぐだけで iQIYI、テンセントビデオ、央視頻（CCTV のアプリ）を見られます。
